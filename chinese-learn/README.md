# 중국어 한 세트 (chinese-learn)

**단어 1개 + 그 단어가 그대로 들어간 즉시 사용 회화 1개**를 한 세트로 묶어
20세트를 소리로 배우고, 배운 것만 골라 **10문제 시험**을 보는 앱입니다.

안드로이드 크롬에서 열고 메뉴의 **"홈 화면에 추가"**를 누르면 앱처럼 전체화면으로 실행됩니다.

배포 주소: `https://<계정>.github.io/homewithreed/chinese-learn/`

---

## 화면

| 탭 | 하는 일 |
|---|---|
| 📚 **학습** | 세트 1~20을 넘겨보며 단어·회화를 듣고, **학습 완료**로 표시 |
| 📝 **시험** | 학습 완료한 세트에서만 10문제 출제 · 문제마다 바로 정답과 해설 · 틀린 세트는 **복습** 버튼으로 바로 이동 |
| 📊 **기록** | 진도(몇 세트 끝냈나), 시험 성적(최고·평균·회차별), 전체 초기화 |

## 소리

- 브라우저 음성 합성(Web Speech API)으로 **기기에 설치된 중국어(zh-CN) 음성**을 씁니다.
- 단어·문장마다 **🔊 듣기**와 **🐢 천천히**(0.5배속) 두 가지 버튼이 있습니다.
- 중국어 음성이 없는 기기에서는 학습 탭 위에 안내가 뜨고, 듣기 문제는 시험에서 자동으로 빠집니다.
  안드로이드 **설정 → 일반 관리 → 언어 → 음성 텍스트 변환(TTS)**에서 중국어(중국)를 내려받으면 들립니다.

## 시험 문제 유형

학습한 세트를 재료로 6가지 유형을 섞어 10문제를 만듭니다.

| 유형 | 문제 |
|---|---|
| `wordMeaning` | 한자를 보고(듣고) 뜻 고르기 |
| `meaningWord` | 뜻을 보고 한자 고르기 |
| `pinyinWord` | 병음을 보고 한자 고르기 |
| `listenWord` | 소리만 듣고 뜻 고르기 |
| `phraseMeaning` | 회화 문장의 뜻 고르기 |
| `phraseBlank` | 회화 문장의 빈칸에 들어갈 단어 고르기 |

- 오답 보기는 **같은 분류(식당·교통 등)에서 먼저** 뽑아 헷갈리게 만듭니다.
- 학습한 세트가 10개보다 적으면 같은 세트를 **다른 유형으로** 다시 내서 10문제를 채웁니다.
- 보기 4개를 만들어야 하므로 **최소 4세트**를 학습해야 시험을 볼 수 있습니다.

## 내용 (20세트)

인사 4 · 소통 3 · 쇼핑 3 · 식당 4 · 교통 3 · 숙소 2 · 위급 1 — 중국 도착 첫날 바로 쓰는 표현 위주.
내용은 `src/data/lessons.ts` 한 파일에 모여 있어 세트를 더하거나 고치기 쉽습니다.
(회화에는 그 세트의 단어가 **글자 그대로** 들어가야 빈칸 문제가 만들어집니다. 테스트가 이를 검사합니다.)

## 개발

```bash
npm install
npm start   # 개발 서버
npm test    # 데이터·시험 출제 로직 테스트
npm run build
```

기록은 브라우저 `localStorage`에만 저장됩니다(서버 없음).
