# 바른 글씨 연습장 (handwriting)

모범 글씨 위에 손가락·펜으로 쓰고 **채점하기**를 누르면 점수와 고칠 점 3가지를 알려 주는 단일 HTML 앱입니다.

* 연습 글자: 자음 · 받침 없는/있는 글자 · 자주 쓰는 말 · 서류용 문장 · 직접 입력
* **따라쓰기**(칸 안에 흐린 모범 글씨) / **보고쓰기**(위에 모범만 보여 주고 빈 칸에 쓰기)
* **한 글자**(큰 칸 하나, ‹ › 로 넘기기) / **한 줄**(여러 칸, 크기·줄 맞춤까지 채점)
* 채점 뒤 모범 글씨가 칸 안에 빨간색으로 겹쳐 보입니다.
* 기록과 **약한 글자**(평균 70점 미만)는 이 기기 브라우저(localStorage)에만 저장됩니다.

## 구름이 모드

위 오른쪽 `구름이` 버튼. 구름이 영어 앱(kumon-math)의 알파벳 따라쓰기와 같은 흐름입니다.

* 코스: 자음 · 모음 · 가나다 · 우리 가족(구름 열매 아빠 엄마) · 인사
* 자음·모음은 **① 획순**: 초록 점에서 시작해 번호 순서·방향대로 그어야 인정(`어떻게 써요?`로 시범). 완성하면 별 1개, 자동으로 ② 단계로.
* **② 따라쓰기**: 흐린 글씨 위에 쓰고 채점. 70점 이상 통과, 별 1~3개(90·80·70점) + 처음 완성 보너스 1개. 못 넘으면 아이 말투 힌트 한 줄.
* `소리 듣기`: 자음 이름(기역, 니은…)이나 글자를 읽어 줍니다(기기 음성 사용).
* 글자 칸 아래 별은 그 글자의 최고 기록. 별·진도는 이 기기 브라우저에만 저장됩니다.

## 채점 방식

내 글씨를 모범 글씨(Gowun Dodum) 크기·자리에 맞춰 겹친 뒤
모양 겹침(F1, 75%) + 크기·위치·가로세로 비율(25%)로 점수를 냅니다.
기울기, 빠진 획, 벗어난 획, 줄 단위 크기·높이 들쭉날쭉을 따로 짚습니다.
획 순서·필압은 보지 않습니다.
