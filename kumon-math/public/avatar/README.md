# 아바타 이미지 폴더

여기에 PNG 이미지(배경 투명)를 넣으면 아바타에 자동으로 표시됩니다.
이미지가 없으면 이모지로 대체되므로, 비어 있어도 앱은 정상 작동합니다.

## 필요한 파일 이름 (전설의 컬렉션)

| 파일명 | 용도 | 권장 크기 |
|---|---|---|
| `diana_crown.png`    | 보석 왕관 (머리 위) | 512×512, 투명 |
| `diana_necklace.png` | 별빛 목걸이 (가슴) | 512×512, 투명 |
| `diana_wings.png`    | 요정 날개 (등 뒤) | 512×512, 투명 |
| `diana_aura.png`     | 반짝이 오라 (전체) | 512×512, 투명 |
| `diana_dress.png`    | 드림 드레스 (전체) | 512×512, 투명 |
| `diana_full.png`     | ✨다이아 요정✨ 전체 아바타 (완성형) | 512×683 세로형, 투명 |

> `diana_full.png` 는 **전체 그림 한 장**으로, 착용하면 아바타가 통째로 이 그림으로 바뀝니다.
> 나머지 조각들은 기본 캐릭터 위에 겹쳐서 표시됩니다(완성 전까지 한 조각씩 모으는 재미).
