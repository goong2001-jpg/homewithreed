# 아바타 이미지 폴더

여기에 **배경이 투명한 WebP** 이미지를 넣으면 아바타에 자동으로 표시됩니다.
이미지가 없으면 이모지로 대체되므로, 비어 있어도 앱은 정상 작동합니다.

배경 제거(크로마키)는 앱 안에서 하지 않습니다. 새 그림을 넣을 때는 미리 투명하게
만들어 두세요 (예: `sharp` 로 `.ensureAlpha()` 뒤 배경 픽셀의 알파를 0으로 → `.webp({ quality: 85 })`).

## 필요한 파일 이름 (전설의 컬렉션)

| 파일명 | 용도 | 크기 |
|---|---|---|
| `diana_crown.webp`    | 보석 왕관 (머리 위) | 512×683, 투명 |
| `diana_necklace.webp` | 별빛 목걸이 (가슴) | 512×683, 투명 |
| `diana_wings.webp`    | 요정 날개 (등 뒤) | 512×683, 투명 |
| `diana_aura.webp`     | 반짝이 오라 (전체) | 512×512, 투명 (검정 배경을 밝기→투명도로 바꿔 둠) |
| `diana_dress.webp`    | 드림 드레스 (전체) | 512×683, 투명 |
| `diana_full.webp`     | ✨다이아 요정✨ 전체 아바타 (완성형) · 기본 캐릭터 | 512×683 세로형, 투명 |

> `diana_full.webp` 는 **전체 그림 한 장**으로, 착용하면 아바타가 통째로 이 그림으로 바뀝니다.
> 아무것도 착용하지 않았을 때의 기본 캐릭터도 같은 파일을 씁니다 (예전 `diana_base.png` 와 같은 그림이었음).
> 나머지 조각들은 기본 캐릭터 위에 겹쳐서 표시됩니다(완성 전까지 한 조각씩 모으는 재미).
