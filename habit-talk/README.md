# 톡톡 습관친구 (habit-talk)

친구 캐릭터들이 **카카오톡처럼 말을 걸어** 아이의 하루 생활습관을 챙겨주는 앱입니다.

정해진 시간에 "일어났어?", "양치했어?", "숙제는 끝냈어?" 같은 메시지가 오고,
아이가 체크하거나 답장하면 친구가 칭찬해주고 "나중에 또 연락하자~" 하며 마무리합니다.

## 기본 시간표

| 시각 | 물어보는 것 |
|---|---|
| 07:30 | 일어났어? |
| 08:00 | 양치 / 아침밥 / 어린이집(학교) 갈 준비 |
| 12:00 | 점심 / 점심 먹고 양치 |
| 17:00 | 손 씻기 / 숙제 / 저녁밥 |

시각도 문항도 설정에서 자유롭게 바꿀 수 있고, 시간대를 더 추가하거나 끌 수도 있습니다.

## 특징

* **카톡 그대로의 화면** — 친구 목록, 안 읽은 메시지 뱃지, 노란 말풍선
* **보내는 친구는 매번 랜덤** — 친구 이름·이모지·색·말투를 설정에서 편집
* **자유 대화** — 규칙 기반이라 요금이 안 들고, 인터넷이 없어도 되고,
  아이에게 이상한 말이 나갈 위험이 없습니다. "ㅇㅇ", "ㄴㄴ", "졸려", "심심해" 같은
  일곱 살이 실제로 치는 말을 넓게 받아줍니다
* **밀린 메시지** — 앱을 늦게 열어도, 그 시간에 온 것처럼 원래 시각으로 쌓여 있습니다
* **별 모으기** — 한 시간대를 다 하면 별 하나
* **푸시 알림** — 앱이 꺼져 있어도 폰 알림이 옵니다 (선택, `habit-push` 필요)

## 폰에 설치하기

앱 안의 **📱 설치 안내**에 기기별 안내가 있습니다. 요약하면:

* **안드로이드** — 크롬으로 열고 ⋮ 메뉴 → 앱 설치
* **아이폰** — **사파리로** 열고 공유 → 홈 화면에 추가

> **아이폰 주의:** 알림은 iOS 16.4 이상에서, **홈 화면에 추가한 앱 안에서만** 됩니다.
> 그리고 사파리와 홈 화면 앱은 저장소가 분리돼 있어서 사파리에서 한 설정이
> 넘어가지 않습니다. 홈 화면 앱에서 설정하거나, 설정 → 백업으로 옮기세요.

## 알림 켜기

기본 상태에서는 앱을 열었을 때 밀린 메시지를 보는 방식으로만 동작합니다.
앱이 꺼져 있어도 알림을 받으려면 [`habit-push`](../habit-push/README.md)의
Cloudflare Worker를 한 번 배포해야 합니다 (무료).

## 개발

```bash
npm install
npm start      # 개발 서버
npm test       # 규칙 엔진 · 시간표 테스트
npm run build  # 배포 빌드
```

설정 화면의 각 시간대에 있는 **"지금 보내보기"** 버튼을 누르면 그 시간대 대화를
바로 확인할 수 있어서, 7시 30분까지 기다릴 필요가 없습니다.

푸시를 로컬에서 시험하려면 `.env.example`을 `.env.local`로 복사해 값을 채우세요.

## 데이터

모든 데이터는 **폰의 localStorage에만** 저장됩니다. 서버로 나가는 것은 푸시를
켰을 때의 알림 시간표와 구독 정보뿐이고, 대화 내용은 폰을 벗어나지 않습니다.

브라우저 데이터를 지우면 사라지므로 **설정 → 백업 내보내기**를 가끔 해두세요.
