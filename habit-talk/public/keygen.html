🔑 알림 키 만들기

푸시 알림에 쓰는 키를 만듭니다. 키는 이 브라우저 안에서만 만들어지고 어디로도 전송되지 않습니다.

만든 값은 Cloudflare KV 에 넣은 뒤 이 페이지를 닫으세요. 메신저나 메모장에 남기지 마세요.

1. KV 에 넣기 — config:vapid

Cloudflare 대시보드 → Storage & Databases → KV → HABIT_KV → Add entry 에서
Key 에 config:vapid, Value 에 아래 내용을 그대로 붙여넣으세요.

2. KV 에 넣기 — config:passphrase

같은 곳에서 Add entry 를 한 번 더 눌러, Key 에 config:passphrase, Value 에 아래 값을 넣으세요.

이 암호는 나중에 폰 앱의 설정 → 알림 암호 에도 똑같이 넣어야 합니다. 여기서 복사해 두세요.
두 개를 다 넣었으면 Cloudflare 에서 저장소를 연결해 Worker 를 배포하면 됩니다. 자세한 순서는 habit-push/README.md 에 있습니다.
