🔑 알림 키 만들기

푸시 알림에 쓰는 VAPID 키 한 쌍을 만듭니다. 키는 이 브라우저 안에서만 만들어지고 어디에도 전송되지 않습니다.

개인키는 비밀입니다. 아래 GitHub 시크릿에 넣은 뒤에는 이 페이지를 닫으세요. 메신저나 메모장에 남기지 마세요.

1. 공개키

공개돼도 되는 값입니다. GitHub 저장소 Settings → Secrets and variables → Actions → Variables 탭에 VAPID_PUBLIC_KEY 라는 이름으로 넣으세요.

2. 개인키 (비밀)

같은 화면의 Secrets 탭에 VAPID_PRIVATE_KEY 라는 이름으로 넣으세요. Variables 가 아니라 Secrets 입니다.

3. 알림 암호

아무나 알림 서버에 등록하지 못하게 막는 암호입니다. Secrets 탭에 PUSH_PASSPHRASE 라는 이름으로 넣고, 나중에 앱 설정 → 알림 암호에도 똑같이 입력하세요.

세 값을 다 넣었으면 GitHub Actions → Deploy push worker 워크플로를 실행하세요.
