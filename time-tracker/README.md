# 내 시간 가계부 (time-tracker)

하루가 **어디로 갔는지** 보이게 하는 시간 기록 앱입니다.
`couple-budget`이 돈의 흐름을, `asset-tracker`가 돈의 잔액을 본다면,
이 앱은 **하루 24시간이라는 예산을 어디에 썼는지**를 봅니다.

배포 주소: `https://<계정>.github.io/homewithreed/time-tracker/`

---

## 화면

| 탭 | 하는 일 |
|---|---|
| ⏱ **오늘** | 분류를 눌러 바로 시작 · 돌아가는 타이머 · 하루 막대 · 시간순 목록 |
| 📊 **돌아보기** | 주간/월간으로 어디에 얼마나 썼나, 지난 기간 대비 증감, 주간 목표 달성 |
| 🗂 **분류** | 분류 추가·수정·삭제, 주간 목표 정하기 |
| ⚙️ **설정** | 백업 내보내기/불러오기, 지운 항목 되살리기, 전체 초기화 |

목록의 **아무 줄이나 누르면** 아래에서 편집 시트가 올라옵니다.

## 기록하는 방법은 둘, 저장되는 모양은 하나

```ts
interface Entry {
  categoryId: string;
  startedAt: number;        // epoch ms
  endedAt: number | null;   // null이면 '지금 돌아가는 중'
  memo: string;
}
```

**`endedAt === null` 이면 진행 중.** 이 규칙 하나로 두 가지가 동시에 풀립니다.

- **타이머**는 따로 있는 물건이 아니라 *아직 끝을 안 적은 기록*입니다.
  메모리에 없고 localStorage에 있으니, 앱을 껐다 켜도 폰을 재부팅해도 계속 돌아갑니다.
- **손으로 적기**와 저장 모양이 같아서 편집 시트도 하나입니다.
  타이머로 만든 기록의 시작 시각을 나중에 고치는 것도 그냥 됩니다.

빠른 시작 그리드에서 다른 분류를 누르면 **돌던 기록이 그 순간 끝나고** 새 기록이 이어집니다.
'멈추고 → 시작하고'가 필요 없어서 탭 한 번으로 끝납니다.
잘못 눌러 1분 안에 옮기면 그 기록은 아예 안 남깁니다 (`MISTAP_MS`) — 휴지통이 3초짜리로 뒤덮이지 않게.

## 이 앱이 답하려는 질문 — "그래서 어디로 샜나"

적어둔 시간만 합치면 "오늘 8시간 일했다"까지밖에 안 나옵니다.
정작 궁금한 건 **아무것도 안 적힌 시간**이라, 계산을 이렇게 나눕니다.

```
흘러간 시간   = min(기간 끝, 지금) − 기간 시작
덮인 시간     = 기록 구간을 겹치지 않게 합친 길이
빈 시간       = 흘러간 시간 − 덮인 시간
```

세 군데서 정직해야 숫자가 안 어긋납니다.

- **겹침을 합친다** — 겹치게 적어놓고 단순히 더해서 빼면 빈 시간이 실제보다 작게 나옵니다.
  `적어둔 시간`은 적힌 그대로(겹치면 24시간을 넘길 수도 있고) 보여주되,
  `빈 시간`은 `mergeRanges()`로 합친 길이로 계산합니다.
- **미래는 빈 게 아니다** — 아직 안 온 시간은 비어 있는 게 아니라 안 산 시간입니다. `지금`에서 끊습니다.
- **미리 적어둔 기록도 미래는 미래다** — 오늘 밤 잘 시간을 미리 적어뒀다고 지금의 빈 자리가 메워지진 않습니다.
  덮인 시간을 셀 때 `지금` 이후는 잘라냅니다.

빈 구간은 화면에서 **누를 수 있는 줄**로 나옵니다. 누르면 그 시간이 채워진 편집 시트가 열립니다 —
'어디로 샜는지 모르겠다'에서 곧장 '그때 뭐 했더라'로 넘어가게.

## 자정을 넘기는 기록

23시 40분에 자서 7시에 깨면 한 기록이 이틀에 걸칩니다.
하루치를 세려면 자정에서 잘라야 하는데, 이걸 화면마다 하면 반드시 어긋납니다.
그래서 **`splitByDay()` 하나만** 통과시킵니다.

```
23:40 ~ 07:00  →  [어제 23:40–24:00, 20분] + [오늘 00:00–07:00, 420분]
```

잘린 조각은 `clippedStart` / `clippedEnd`를 달고 나와 화면에 `↑`, `다음날로 이어짐`으로 표시됩니다.
타이머를 며칠째 안 껐어도 날짜별로 전부 쪼개집니다.

손으로 적을 때도 마찬가지입니다. **끝이 시작보다 이르면 다음날로 봅니다** —
`23:30 ~ 01:00`은 거꾸로 흐른 시간이 아니라 밤을 넘긴 90분입니다.
이걸 오류로 막으면 야근도 수면도 적을 수가 없습니다.

날짜 경계는 전부 **지역시각**으로 잡습니다. UTC로 자르면 한국 새벽의 기록이 어제로 밀립니다.

## 주간 목표 — 늘리고 싶은 시간과 줄이고 싶은 시간

운동은 `주 3시간 이상`이 목표지만, 딴짓은 `주 5시간 이하`가 목표입니다.
같은 숫자라도 넘겼을 때 칭찬할 일인지 경고할 일인지가 **정반대**라 방향(`goalKind`)을 같이 저장합니다.

```
이 기간 목표 = 주간 목표 × (기간 일수 ÷ 7)
지켰나       = '이상'이면 채웠나, '이하'면 안 넘겼나
```

지난 기간 대비 증감도 이 방향으로 색을 정합니다.
목표를 안 잡은 분류는 늘었다고 빨갛게 칠하지 않습니다 — 늘어난 게 다 나쁜 건 아니니까요.

## 데이터는 어디에

**이 브라우저의 localStorage에만 있습니다.** 서버로 아무것도 보내지 않습니다.

그래서 브라우저 데이터를 지우거나 폰을 바꾸면 **그대로 사라집니다.**
가끔 **설정 → 백업 파일로 내보내기**를 눌러 JSON 파일을 받아두세요. 이게 유일한 방어선입니다.

불러오기는 지금 기록 위에 **합칩니다**(`utils/merge.ts`의 `mergeById`).
항목마다 `id`와 `updatedAt`이 있고 삭제도 툼스톤(`deleted: true`)으로 남기 때문에,
백업을 얹어도 지운 항목이 되살아나지 않고 더 최근에 고친 쪽이 남습니다.

폰에서 **공유 → 홈 화면에 추가**를 하면 앱 아이콘으로 열리고, 저장한 기록도 더 오래 남습니다.

## 개발

```bash
cd time-tracker
npm ci
npm start                      # http://localhost:3000
npm test -- --watchAll=false   # time / entry / summary
npm run build
```

### 구조

```
src/
  App.tsx                # 탭 라우팅 + summarize()를 돌리는 useMemo들
  types/index.ts         # 도메인 타입과 상수 전부
  hooks/
    useTracker.ts        # localStorage CRUD + start/stop (삭제는 툼스톤)
    useNow.ts            # 흘러가는 '지금'
  components/            # 화면과 편집 시트. 전부 인라인 style
  utils/
    time.ts    + .test   # 날짜·시각·길이 (지역시각 기준)
    entry.ts   + .test   # 자정 분할, 빈 구간, 겹침
    summary.ts + .test   # 기간 집계, 목표 달성, 기간 비교
    merge.ts, storage.ts, backup.ts, id.ts
```

**시간 계산은 반드시 `utils/`의 순수 함수에 두고 `.test.ts`를 같이 씁니다.**
'지금'은 항상 인자로 주입해서 테스트가 시계에 의존하지 않게 합니다 —
`asset-tracker/src/utils/date.ts`, `couple-budget/src/utils/budget.ts`와 같은 관행입니다.

컴포넌트는 계산하지 않습니다. `App.tsx`가 `segmentsOfDay` · `gapsOf` · `summarize`를 돌리고
결과만 내려줍니다. 딱 한 곳, `RunningCard`만 1초짜리 시계를 따로 갖습니다 —
경과 시간이 분 단위로만 움직이면 멈춘 것처럼 보이기 때문입니다.
반대로 화면 전체는 30초에 한 번만 다시 그립니다.

### 스타일

Tailwind도 CSS 모듈도 쓰지 않습니다. 전부 인라인 `style={{}}`이고,
공유하는 값(카드·색·행·버튼)은 `src/components/ui.ts`에 모여 있습니다.
`index.css`는 리셋과 애니메이션 세 개뿐입니다.
