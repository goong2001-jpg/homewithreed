# 우리집 일주일 식단 (family-meal)

**7살 · 16개월 아기 · 엄마 · 아빠가 같은 상에서 먹을 수 있는 일주일 식단을 자동으로 짜는 앱**입니다.
식단만 주는 게 아니라 레시피와 장보기 목록까지 한 번에 나옵니다.

배포 주소: `https://<계정>.github.io/homewithreed/family-meal/`

---

아침 12 · 점심 한 그릇 16 · 국 16 · 메인 20 · 곁들임 18, **총 82개 레시피**로 식단을 조합합니다.

## 화면 다섯 개

| 탭 | 하는 일 |
|---|---|
| 🍽️ 식단 | 월~일 7일 × 아침·점심·국·메인·곁들임. 메뉴를 누르면 레시피, 🔄 를 누르면 그 한 끼만 교체 |
| 🧊 냉장고 | **지금 집에 있는 걸 넣으면 그걸로 만들 수 있는 메뉴**를 살 것이 적은 순으로 |
| 🛒 장보기 | 일주일치 재료를 마트 코너별로 합산. 체크리스트 + 목록 복사 + 요일별 보기 |
| 🥗 영양 | 이번 주 식단이 균형 기준 6개를 통과하는지, 단백질원이 몰리지 않았는지 |
| ⚙️ 설정 | 인분 수, 뺄 재료, 장보기 줄이기, 최대 조리 시간, 매운 메뉴 제외, 입맛 기록 관리 |

---

## 무엇을 우선하나 — 다양성이 먼저입니다

**같은 메뉴가 매주 나오면 그 식단은 안 씁니다.** 그래서 순서를 이렇게 잡았습니다.

1. **다양성** — 지난 몇 주에 올렸던 메뉴는 크게 뒤로 밀립니다.
2. **장보기 부담** — 이미 사기로 한 재료를 다시 쓰는 메뉴를 앞세웁니다.
3. **영양 균형** — 최우선이 아니라 **지켜야 할 하한선**입니다.

초기 버전은 이 순서가 반대였고, 그래서 **어묵탕이 50주 중 50주 나왔습니다.**
"생선 주 2회" 규칙이 국에도 걸려 있었는데 생선 국이 어묵탕 하나뿐이라, 규칙이 매주 같은 국을 강제하고 있었습니다.
생선은 메인으로만 채우게 고치고, 레시피를 56 → 82개로 늘리고, 지난 주 메뉴를 피하게 했습니다.

| 지표 (50주 이상 돌린 실측) | 고치기 전 | 지금 |
|---|---|---|
| 한 메뉴의 최다 등장률 | 100% (어묵탕) | 52% |
| **지난 주와 겹치는 메뉴 수** (주 25가지 중) | — | **최대 1개** |
| 주간 장보기 품목 (양념 제외) | 53.8개 | **40.6개** |

### 영양은 하한선으로 지킵니다

**칼로리 숫자는 일부러 내지 않습니다.** 가정식은 계량 오차가 커서 "1인분 480kcal" 같은 숫자를 붙이면
틀린 값을 맞는 값처럼 보이게 만듭니다. 대신 식품군이 골고루 들어갔는지를 셉니다.

| 기준 | 목표 | 이유 |
|---|---|---|
| 단백질원 종류 | 주 4종 이상 | 소·돼지·닭·생선·새우·달걀·콩을 돌려 씁니다 |
| 생선 반찬 | 주 2회 이상 | 아이 성장기 기준 (국이 아니라 메인으로 채웁니다) |
| 채소 넉넉한 날 | 7일 모두 | 하루에 채소가 주인공인 메뉴 두 개 이상 |
| 칼슘 메뉴 | 주 4회 이상 | 두부·치즈·우유·멸치·미역 |
| 매운 메뉴 | 주 2회 이하 | 아기는 못 먹고 7살도 부담스러움 |
| 손 많이 가는 저녁 | 주 2회 이하 | 저녁 세 가지 합쳐 1시간 넘는 날 |

매운 메뉴와 저녁 조리 시간은 **점수가 아니라 후보에서 아예 빼서** 지킵니다 — 점수로만 밀면 다양성 쪽 난수에 밀려 새 나갑니다.
나머지는 다양성을 앞세운 대가로 **열 주에 한 주 정도는 한 항목이 모자랄 수 있고**, 그런 주는 영양 탭에 ⚠️ 로 그대로 보여 줍니다. 숨기지 않습니다.

여기에 더해 같은 날 점심·국·메인의 단백질원과 주재료가 겹치지 않게 하고,
메인·점심은 일주일에 한 번씩만 나오게 합니다.

## 장보기를 줄이는 방법

설정의 **장보기 줄이기**(기본 켜짐)가 세 가지를 합니다.

1. **반찬은 이틀씩 먹습니다.** 주 7개가 아니라 4개만 만듭니다. 식단 화면에 *만들어 둔 것* 으로 표시되고, 그날 조리 시간에서도 빠집니다.
2. **아침은 네 가지를 돌려 먹습니다.** 매일 다른 아침을 차리는 집은 없습니다.
3. **이미 사기로 한 재료를 다시 쓰는 메뉴를 앞세웁니다.** 메뉴는 다르되 장바구니는 겹치게 하는 것이 목적입니다.

끄면 매일 새로 만드는 식단이 나오고, 장보기 품목은 그만큼 늘어납니다.

### 요일별 목록

장보기 탭의 **요일별** 버튼을 누르면 그날 **실제로 만드는** 메뉴의 재료만 나옵니다.
어제 만들어 둔 반찬을 먹는 날은 그 재료가 빠집니다.
주말에 한 번 장을 보고, 이 목록으로 무엇을 언제까지 써야 하는지 확인하는 용도입니다.
담기(체크)는 주간 목록에서만 합니다 — 같은 재료가 여러 날에 나뉘어 있어 요일별에서 체크하면 셈이 어긋납니다.

## 안 먹는 메뉴는 앱이 기억합니다

한 주 돌려 보면 반드시 안 먹는 메뉴가 나옵니다. 레시피 화면 아래 버튼 두 개로 그 자리에서 처리합니다.

- **⭐ 잘 먹어요** → 다음 추천부터 먼저 뽑습니다. 식단 화면에 ⭐ 로 표시됩니다.
- **안 먹어요** → **이번 주 상에서 바로 내리고**(그 한 자리만 다른 메뉴로 교체), 앞으로도 추천하지 않습니다.

별표 하나 눌렀다고 이번 주 상을 통째로 바꾸면 놀라니, **잘 먹어요는 저장만 하고 식단은 건드리지 않습니다.**
뺀 메뉴만 그 자리를 즉시 갈아 끼웁니다. 둘 다 설정 → *식구들 입맛* 에서 되돌릴 수 있습니다.

한 자리(예: 국)의 메뉴를 전부 빼 버리면 빈 상을 내는 대신 제외 목록을 잠시 풀어 채웁니다.

## 냉장고 탭 — 지금 뭐 해먹지

집에 있는 재료를 넣으면 **그걸로 만들 수 있는 메뉴를 살 것이 적은 순으로** 보여 줍니다.

- **지금 바로 만들 수 있어요** — 더 살 게 없는 메뉴
- **한 가지만 사면 / 두 가지 사면** — 무엇을 사야 하는지 이름까지 적혀 있습니다
- 자리(메인·국·반찬·한 그릇·아침)로 걸러 볼 수 있고, 메뉴를 누르면 레시피가 열립니다

간장·참기름 같은 **상비 양념과 쌀·밥은 있는 것으로 칩니다.** 그것까지 세면 만들 수 있는 게 하나도 안 나옵니다.
알레르기·매운 메뉴 제외·안 먹는 메뉴 설정은 여기서도 그대로 지킵니다.

### 재료 이름은 어떻게 알아보나

`애호박` 처럼 짧게 적어도 되고, `소고기` 라고 적으면 *소고기 국거리·불고기용 소고기* 가 다 걸립니다.
`닭고기 → 닭안심·닭다리`, `생선 → 삼치·고등어·연어` 처럼 부르는 이름이 다른 것도 연결해 뒀습니다.
자주 쓰는 재료 18개는 버튼으로 한 번에 넣습니다.

**단순 부분 일치는 쓰지 않습니다.** `두부` 가 `순두부` 까지 잡으면, 순두부가 없는데도 "바로 만들 수 있다"고 말하게 됩니다.
재료 이름을 낱말로 쪼개 **낱말과 같거나 그 낱말이 시작되는 경우만** 인정합니다 (`무` 같은 한 글자는 딱 맞을 때만).

### 여기 적은 재료는 주간 식단에도 쓰입니다

1. 그 재료를 쓰는 메뉴를 **주간 식단 추천에서도 먼저 뽑습니다.**
2. **장보기 목록에서 빠집니다.** "집에 있어서 뺐습니다" 칸으로 내려가고, 복사한 글에도 안 들어갑니다.

다만 **재료를 넣는다고 이번 주 식단이 저절로 바뀌지는 않습니다.** 재료 하나 넣을 때마다 상이 뒤집히면 쓸 수가 없어서,
냉장고 화면 아래 *이 재료로 이번 주 식단 다시 짜기* 버튼을 눌러야 다시 짜입니다.

> **주의**: 냉장고 재료는 "있다/없다"만 봅니다. 양은 세지 않으므로 애호박 반 개만 남았는데 세 메뉴에 쓰이면 모자랍니다.
> 그래서 장보기 목록에 필요한 총량을 같이 적어 뒀습니다 — 모자라면 냉장고 탭에서 그 재료를 지우면 다시 목록에 올라옵니다.

## 장보기 목록

- 일주일 식단의 모든 재료를 **이름+단위로 합산**합니다. 당근이 다섯 메뉴에 들어가면 한 줄로 묶입니다.
- **마트 코너 순서**(채소·과일 → 정육 → 수산 → 유제품·달걀 → 쌀·면·가공 → 양념)로 묶어 동선대로 담게 했습니다.
- 각 줄 아래에 **어느 메뉴에 쓰는 재료인지** 적혀 있어서, 빼먹었을 때 무슨 요리가 안 되는지 바로 압니다.
- 간장·참기름 같은 **상비 양념은 기본으로 접혀 있습니다** (설정에서 켤 수 있음).
- **'밥'은 목록에 뜨지 않습니다.** 필요한 공기 수를 생쌀 무게로 환산해 '쌀'로 바꿔 담습니다.
- 수량은 4인분 기준으로 적힌 레시피를 설정한 인분 수로 환산한 값입니다. 자잘한 소수는 계량하기 쉬운 값으로 반올림합니다.
- **반찬을 이틀 먹어도 재료는 한 번 분량입니다.** 시금치 한 단, 콩나물 400g처럼 반찬 레시피는 원래 여러 끼 나오는 양이라 그대로 뒀습니다. 양이 빠듯하면 그 재료만 조금 더 사세요.

## 인분 수

기본값은 **3인분**입니다. 어른 2 + 7살 + 아기를 실제로 먹는 양으로 환산하면 대략 이 정도입니다.
설정에서 1~8인분으로 바꾸면 레시피 재료와 장보기 목록이 함께 움직입니다.

## 같은 식단이 다시 나오는 이유

식단은 **씨앗(seed) 하나로 결정**됩니다. 같은 씨앗 + 같은 설정이면 언제 열어도 같은 식단이 나오고,
새로고침해도 흔들리지 않습니다.

식단을 새로 만들 때마다 **직전 식단의 메뉴가 이력에 쌓여** 다음 추천에서 뒤로 밀립니다(최근 90개까지 기억).

- **다시 추천** = 새 씨앗으로 완전히 새 식단
- **설정 변경** = 씨앗은 그대로 두고 조건만 반영 (결이 비슷한 식단이 나옵니다)
- **🔄 / 안 먹어요** = 그 한 끼만 교체 (나머지 상은 그대로)

식단이 바뀌면 필요한 재료도 달라지므로 장바구니 체크는 자동으로 비워집니다.

## 레시피를 추가하려면

`src/data/recipes.ts` 에 항목 하나를 더하면 끝입니다. 추천 로직은 건드릴 필요가 없습니다.

```ts
{
  id: 'm-example',
  name: '메뉴 이름',
  slot: 'main',          // breakfast | onedish | soup | main | side
  minutes: 20,
  ease: 1,               // 1 아주 쉬움 · 2 보통 · 3 손이 좀 감
  protein: 'chicken',
  veg: 2,                // 0 없음 · 1 곁들임 · 2 채소가 주인공
  calcium: true,         // 두부·치즈·멸치·미역이 들어갈 때만
  spicy: false,          // 안 매우면 아예 안 써도 된다
  allergens: ['대두'],
  ingredients: [meat('닭안심', 500, 'g'), sauce('간장', 3, '큰술')],
  steps: ['...'],
  babyTip: '아기 몫은 ...',   // 필수
  kidTip: '7살은 ...',        // 선택
}
```

`allergens` 는 설정에서 그 재료를 뺐을 때 이 메뉴를 걸러내는 데 쓰이므로 빠짐없이 적어야 합니다.

## 개발

```bash
npm install
npm start     # 개발 서버
npm test      # 55개 테스트 (다양성 · 장보기 절감 · 냉장고 매칭 · 영양 하한선)
npm run build
```

데이터는 전부 브라우저 `localStorage` 에 저장됩니다. 서버도, 계정도 없습니다.
