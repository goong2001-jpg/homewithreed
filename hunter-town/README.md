# 헌터 마을 (hunter-town)

**시간마다 새 헌터가 마을 입구에 찾아오고, 받아들인 헌터들이 알아서 사냥하는 걸 구경하는** 나만의 방치형 헌터 타이쿤입니다.
장비를 바꿔 주면 헌터 모습과 타격감이 바로 달라지고, 숨은 **신 모드**로 게임 규칙을 내 마음대로 고칩니다.
서버 없이 이 기기 브라우저 `localStorage` 에만 저장합니다.

안드로이드 크롬에서 열고 **"홈 화면에 추가"** 를 누르면 앱처럼 실행됩니다.
배포 주소: `https://<계정>.github.io/homewithreed/hunter-town/`

## 화면

| 영역 | 하는 일 |
|---|---|
| 🚪 **마을 입구** | 정해진 간격(기본 10분)마다 헌터가 한 명씩 찾아옵니다. 직업·등급·특성이 무작위. **받아들이기** / **돌려보내기** |
| 🌲 **사냥터** (canvas) | 받아들인 헌터가 바로 사냥터로 나가 몬스터와 싸웁니다. 20마리 잡으면 보스, 보스를 잡으면 다음 구역 |
| 🧑‍🤝‍🧑 **헌터** 탭 | 헌터 카드(체력·경험치 바). 탭하면 상세 시트 → 무기·갑옷 교체, 사냥/휴식, 내보내기 |
| 🎒 **장비** 탭 | 사냥에서 주운 장비 창고. 팔기, 대장간에서 만들기 |
| 🏘️ **마을** 탭 | 숙소(정원) · 대장간(제작 등급) · 훈련소(경험치) · 회복의 성소(쓰러진 뒤 회복) 업그레이드 |
| 📜 **기록** 탭 | 누가 왔고, 뭘 주웠고, 누가 쓰러졌는지 |

## 헌터

* 직업 4종: 🗡️ 전사(검, 근접·튼튼) · 🏹 궁수(활, 원거리·빠름) · 🔮 마법사(지팡이, 원거리·강함) · ✨ 성직자(철퇴, 동료 치유)
* 등급 C · B · A · S · **S+** — 기본 능력치 배율이 다르고 색이 다릅니다 (회색·초록·파랑·보라·금색)
* 특성 1~2개: 힘센, 튼튼한, 날쌘, 행운의, 부지런한, 욕심쟁이 / 겁쟁이, 허약한, 느린, 덜렁이, 게으른
* 레벨업마다 능력치 7% 성장. 쓰러지면 마을에서 회복한 뒤(기본 60초) 자동으로 다시 사냥터로.
* 숙소 정원 = 3 + 숙소 레벨. 꽉 차면 받아들일 수 없습니다.

## 장비와 타격감

* 무기는 직업 전용(검·활·지팡이·철퇴), 갑옷은 공용. 등급 C~S+.
* **장착하면 바로 바뀌는 것**: 무기 길이·색·빛(S 이상은 발광), 갑옷 색과 테두리, 파편 수, 화면 흔들림, 히트스톱(멈칫), 타격음 크기·길이.
* 몬스터는 8% 확률(보스는 100%)로 장비를 떨어뜨립니다. 구역이 올라갈수록 좋은 장비가 나옵니다.
* 대장간에서 골드 + 🪵나무 + ⛏️광석으로 제작. 💎보석이 있으면 절반 확률로 써서 S+ 확률이 올라갑니다.

## 자리를 비운 동안

앱을 닫아도 **헌터 등장 시계는 계속 갑니다**(입구 대기 최대 3명). 다시 열면 그동안 온 헌터와,
마지막 플레이에서 측정한 분당 수입의 절반 × 지난 시간(최대 8시간)만큼의 골드를 정산해 알려 줍니다.

## ✨ 신 모드 (관리자)

화면 위 **제목을 3초 안에 7번 탭**하거나 주소 끝에 `#god` 를 붙여 엽니다. 바꾼 값은 저장됩니다.

| 항목 | 설명 |
|---|---|
| 등장 간격 · 입구 대기 · 등급 가중치 | 헌터가 얼마나 자주, 얼마나 좋은 등급으로 오는지 |
| 📯 지금 헌터 부르기 · 내 헌터 만들기 | 이름·직업·등급을 정해 바로 입구에 세웁니다 |
| 경험치·골드·몬스터 강함 배율, 드롭 확률, 회복 시간, 정원 보너스 | 성장 속도와 난이도 |
| 흔들림 · 멈칫 · 파편 | 타격감 강도 (0이면 끔, 3이면 과격) |
| 장비 만들기 | 종류·등급을 골라 창고에 넣습니다 |
| 자원 | 골드 +10,000 · 재료 +100 · 구역 +1 |
| 내보내기 / 가져오기 / 전부 초기화 | 저장 데이터(JSON) 백업·복원 |

## 파일

* `index.html` 화면 뼈대 · `style.css` 스타일 · `app.js` 게임 전체(데이터 정의 → 생성 → 시뮬레이션 → 그리기 → 화면 → 신 모드)
* `sw.js` 오프라인 껍데기 캐시 · `manifest.json` 홈 화면 설치 · `version.json` 버전
* `test/smoke.js` Playwright 스모크 테스트 — 아래처럼 실행

```
cd hunter-town
python3 -m http.server 8152 &
node test/smoke.js
```

규칙 수치는 `app.js` 맨 위 `DEFAULT_CFG`, 직업·등급·특성·구역 표는 그 아래 데이터 정의에 있습니다.

## 만든 이유

이블헌터타이쿤에서 좋아하던 세 가지 — 헌터가 시간마다 새로 오는 것, 헌터들이 사냥하는 걸 보는 것, 장비를 바꿔 주면 모습과 타격감이 변하는 것 — 를
그림·이름·수치를 전부 새로 만들어 혼자 쓰는 버전으로 옮긴 것입니다. 원작의 에셋이나 데이터는 쓰지 않았습니다.
