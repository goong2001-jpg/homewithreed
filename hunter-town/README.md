# 헌터 마을 (hunter-town)

**시간마다 새 헌터가 마을에 찾아오고, 받아들인 헌터들이 알아서 사냥하는 걸 구경하는** 나만의 픽셀 방치형 헌터 타이쿤입니다.
장비를 바꿔 주면 헌터 모습과 타격감이 바로 달라지고, 헌터들은 아래 수다창에서 떠들고, 숨은 **신 모드**로 게임 규칙을 내 마음대로 고칩니다.
서버 없이 이 기기 브라우저 `localStorage` 에만 저장합니다.

그림은 전부 코드로 그린 픽셀 스프라이트입니다. 캔버스를 낮은 해상도(화면 3픽셀 = 게임 1픽셀)로 그린 뒤 확대해서 픽셀 느낌을 냅니다.

안드로이드 크롬에서 열고 **"홈 화면에 추가"** 를 누르면 앱처럼 실행됩니다.
배포 주소: `https://<계정>.github.io/homewithreed/hunter-town/`

## 경제 — 헌터가 손님이다

* 몬스터가 떨어뜨리는 **골드와 잡템은 헌터 개인 것**입니다(주머니 🪙, 가방 🎒 최대 10칸). 장비도 주운 헌터 가방으로.
* 마을(사용자) 금고 수입은 ① 헌터가 잡화상에 잡템을 팔 때 내는 **세금 10%**(잡화상 레벨당 +1%) ② **헌터들이 상점에서 사는 돈** ③ 오늘 할 일 보상.
* **정비(사냥 가기 전 필수)**: 잡화상에서 잡템 판매(약초는 마을 🌿로) → 물약상점에서 물약 3개까지 구매 → 무기상점·방어구상점에서 지금 것보다 좋고 살 수 있는 장비가 있으면 구매·장착(쓰던 건 창고로) → 출발. 주운 장비가 더 좋으면 스스로 장착합니다.
* 사냥 한 번은 처치 10+레벨×2마리, 가방이 차거나 체력이 낮은데 물약이 없으면 먼저 돌아옵니다(출발 뒤 8초는 예외). 사냥 중 체력 40% 아래면 물약을 마십니다. 마을에 있으면 체력이 회복되고 출발할 때는 완전 회복입니다.
* 상점 운영: 🌿 약초 1개 = 물약 1개(양조 버튼 4번 연타), 가격 10/15/25. 장비는 창고에서 가격을 붙여 진열(칸 수 = 2 + 상점 레벨), 헌터는 더 좋고 돈이 있을 때만 삽니다.

아래 5칸 메뉴(건설·헌터·창고·대장간·기록)는 패널이 열려 있어도 보여서 바로 다른 패널로 넘어갈 수 있습니다.

## 헌터

* 직업 4종: 🗡️ 전사(검, 근접·튼튼) · 🏹 궁수(활, 원거리·빠름) · 🔮 마법사(지팡이, 원거리·강함) · ✨ 성직자(철퇴, 동료 치유)
* 외모: 머리 모양 5종(짧은·긴·포니테일·모자·올림) × 머리색 11 × 피부색 3 이 헌터마다 무작위. 옷 색은 직업 색
* 등급 C · B · A · S · **S+** — 기본 능력치 배율이 다르고 색이 다릅니다 (회색·초록·파랑·보라·금색)
* 특성 1~2개: 힘센, 튼튼한, 날쌘, 행운의, 부지런한, 욕심쟁이 / 겁쟁이, 허약한, 느린, 덜렁이, 게으른
* 레벨업마다 능력치 7% 성장. 쓰러지면 마을에서 회복한 뒤(기본 60초) 자동으로 다시 사냥터로.
* 숙소 정원 = 3 + 숙소 레벨. 꽉 차면 받아들일 수 없습니다.

## 장비와 타격감

* 무기는 직업 전용(검·활·지팡이·철퇴), 갑옷은 공용. 등급 C~S+.
* **옵션(파밍 요소)**: 등급별 옵션 개수 C0 · B1 · A2 · S3 · S+4, 수치 범위 B 2~5% · A 3~8% · S 5~12% · S+ 8~18%. 종류는 공격력·공격속도·이동속도·치명타·치명타 피해·체력·방어력·골드 획득·경험치·드롭률·흡혈 11가지 중 무작위. 같은 등급이라도 옵션이 다르니 좋은 걸 찾는 재미가 있습니다.
* **강화**: 창고에서 광석+골드로 +1씩, 성공률 100→20%(대장간 레벨당 +2%), 실패하면 재료만 잃습니다. +1마다 기본 능력 +10%.
* **장착하면 바로 바뀌는 것**: 무기 길이·색·빛(S 이상은 발광 테두리), 갑옷 색(옷에 등급 색이 섞임)·어깨 장식(A 이상)·가슴 장식(S 이상)·망토(S+), 파편 수, 화면 흔들림, 히트스톱(멈칫), 타격음 크기·길이.
* 몬스터는 8% 확률(보스는 100%)로 장비를 떨어뜨립니다. 구역이 올라갈수록 좋은 장비가 나옵니다.
* 대장간에서 골드 + 🪵나무 + ⛏️광석으로 제작. 💎보석이 있으면 절반 확률로 써서 S+ 확률이 올라갑니다.

## 사용자가 직접 하는 것

* **촌장의 일격**: 사냥터에서 몬스터를 탭하면 최대 체력 8%만큼 때립니다.
* **📣 함성**: 20초 동안 모든 헌터 공격속도 +40%, 90초 쿨타임.
* 물약 양조(연타), 장비 강화(확률), 진열과 가격 정하기, 건설 순서 정하기, 헌터 받을지 돌려보낼지.

## 절전 모드와 오프라인

* **🌙 절전**: 화면을 검게 하고 시계·누적 수입만 보여 주면서 마을은 그대로 돌아갑니다(보상 100%). 화면 꺼짐 방지(Wake Lock)를 켭니다. 탭하면 해제.
* **오프라인**(앱을 닫음): 최대 24시간까지, 마지막 플레이에서 측정한 분당 수입(금고 골드·경험치·처치·장비 드롭·헌터 주머니)의 **50%**로 정산합니다. 헌터 등장 시계는 100%로 갑니다. 비율과 최대 시간은 신 모드에서 바꿀 수 있습니다.

## 파일

* `index.html` 화면 뼈대 · `style.css` 스타일 · `app.js` 게임 전체(데이터 정의 → 생성 → 2D 시뮬레이션 → 픽셀 그리기 → 화면 → 신 모드)
* 헌터 스프라이트는 `drawHunter`, 무기는 `drawWeapon`, 몬스터는 `drawMonster`, 구역 배경은 `buildTerrain`, 지도(하늘·마을·성벽·사냥터)는 `buildMap`, 건물은 `drawHouse`. 헌터 대사는 `LINES`
* 정비 흐름은 `stepTown` → `doPhase`(sell·potion·shop·ready), 장비 옵션은 `OPTS`·`rollOpts`, 오프라인 정산은 `trackRate`·`offlineCatchUp`
* `sw.js` 오프라인 껍데기 캐시 · `manifest.json` 홈 화면 설치 · `version.json` 버전
* `test/smoke.js` Playwright 스모크 테스트 — 아래처럼 실행

```
cd hunter-town
python3 -m http.server 8152 &
node test/smoke.js
```

규칙 수치는 `app.js` 맨 위 `DEFAULT_CFG`, 직업·등급·특성·구역 표는 그 아래 데이터 정의에 있습니다.

## 만든 이유

이블헌터타이쿤에서 좋아하던 세 가지 — 헌터가 시간마다 새로 오는 것, 헌터들이 사냥하는 걸 보는 것, 장비를 바꿔 주면 모습과 타격감이 변하는 것 — 를
그림·이름·수치·대사를 전부 새로 만들어 혼자 쓰는 버전으로 옮긴 것입니다. 픽셀 아트, 밤 마을, 수다창, 아래 큰 메뉴 같은 **분위기**만 참고했고 원작의 에셋이나 데이터는 쓰지 않았습니다.
