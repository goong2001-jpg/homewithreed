# 내 자산관리 (asset-tracker)

전세보증금·대출·예적금·투자를 **잔액 기준**으로 관리하는 개인 자산관리 앱입니다.
`couple-budget`이 매달 들어오고 나가는 **흐름**을 본다면, 이 앱은 **지금 얼마를 갖고 있고 얼마를 빚졌는지**를 봅니다.

배포 주소: `https://<계정>.github.io/homewithreed/asset-tracker/`

---

## 화면

| 탭 | 하는 일 |
|---|---|
| 📊 **한눈에** | 순자산 · 자산 구성 · 매달 나가는 돈 · 다가오는 만기 · 자산/대출 목록 |
| 💰 **자산** | 분류별로 자산을 넣고 고치기. 분류 자체도 추가·수정·삭제 |
| 💳 **나가는돈** | 대출(남은 원금·월 상환액·진행률)과 고정비 |
| 🎯 **목표** | 입주자금 같은 목돈 목표. 달성률과 매달 모을 금액 |
| 📈 **추이** | 달마다 남긴 순자산 스냅샷을 선으로 이은 그래프와 전월 대비 표 |
| ⚙️ **설정** | 백업 내보내기/불러오기, 만기 일정 캘린더 내보내기, 오프라인 상태, 지운 항목 되살리기, 전체 초기화 |

목록의 **아무 줄이나 누르면** 아래에서 편집 시트가 올라옵니다. 따로 '수정' 버튼을 찾을 필요가 없습니다.

```
순자산 = 총자산 − 남은 대출 원금
매달 나가는 돈 = 대출 월 상환액 + 고정비
```

### 내 몫 — 걸린 대출을 뺀 진짜 내 돈

전세보증금 9,900만원을 대출 6,600만원 + 내 돈 3,300만원으로 마련했다면,
보증금 전액이 자산인 건 맞지만 **그게 다 내 돈은 아닙니다.**

대출 편집의 **어떤 자산 때문에 빌렸나요**(`Loan.linkedAssetId`)로 연결해두면,
자산 목록에 평가액과 함께 **내 몫 3,300만원**이 같이 뜹니다.

```
내 몫 = 평가액 − 연결된 대출의 남은 원금   (음수면 0)
```

연결하지 않은 대출(신용대출 등)은 특정 자산의 몫을 깎지 않고 순자산에서만 빠집니다.
중도상환으로 직접 적은 남은 원금도 그대로 반영됩니다.

### 목표 — 얼마나 준비됐나

분양가만 보면 실제로 내가 마련할 돈이 안 보입니다. `utils/goal.ts`가 한 줄로 정리합니다.

```
내가 모아야 할 돈 = (실제 계약금 + 부대비용) − 예상 대출
달성률           = 준비된 돈 ÷ 내가 모아야 할 돈
매달 모을 돈      = 아직 모자란 돈 ÷ 목표일까지 남은 개월
```

- **실제 계약금**(`netPrice`)을 적으면 그걸 쓰고, 비우면 총 분양가를 씁니다. 옵션 제외 금액이 따로일 때 필요합니다
- **부대비용**(`extraCost`) — 취득세·중개비·이사비는 분양가에 안 잡히는데 입주 때 목돈으로 나갑니다. 빼먹으면 막판에 모자랍니다
- **준비된 돈**을 무엇으로 볼지 고릅니다: `운용 가능한 돈`(묶임 제외) / `전체 자산`(전세금을 입주자금으로 쓸 때) / `직접 고르기`
- 어느 쪽이든 평가액이 아니라 **대출을 뺀 내 몫**으로 셉니다
- 목표일이 지났는데 못 모았으면 `overdue`로 표시하고 매달 계산은 하지 않습니다(남은 기간이 없으니까)

### 언제 쓸 수 있나 — 유동성 3단계

보증금 9,900만원과 통장 300만원을 똑같이 '자산'으로만 세면
"지금 당장 쓸 수 있는 돈이 얼마인가"에 답할 수 없습니다.

| 단계 | 뜻 | 기본으로 들어가는 분류 |
|---|---|---|
| 💵 지금 바로 | 통장 잔고, 파킹통장, 현금 | 현금 |
| ⏳ 며칠이면 | 주식·펀드(팔면 2~3일), 중도해지 가능한 예적금 | 예적금·청약, 투자 |
| 🔒 묶여 있음 | 전세보증금, 부동산, 청약, 퇴직연금 | 보증금·부동산, 기타 |

`Asset.liquidity`가 `null`이면 **분류 기본값**(`DEFAULT_LIQUIDITY`)을 따릅니다.
사용자가 만든 분류는 `'묶임'`으로 떨어집니다 — 가용자금을 부풀리는 쪽으로 틀리면 안 되니까요.

홈의 **지금 쓸 수 있는 돈**은 `'즉시'` 자산의 **내 몫** 합계입니다.
주식담보대출처럼 유동자산에 빚이 걸린 경우까지 정직해집니다.

단계 줄을 누르면 **그 안에 든 자산이 펼쳐집니다**(한 번에 한 단계).
대출이 걸려 평가액과 내 몫이 다를 때는 `평가액 8,766만원 · 대출 6,613만원`처럼 근거를 같이 보여줍니다.
펼친 자산을 누르면 바로 편집 시트가 열립니다.

### 추이 — 지난달엔 얼마였나

이 앱은 '지금' 잔액만 들고 있어서 그대로 두면 지난달에 얼마였는지 알 길이 없습니다.
그래서 `utils/snapshot.ts` 가 **달마다 한 줄씩** 순자산을 남깁니다 (`Snapshot`, id는 `snap_YYYY-MM`).

- 앱을 열 때와 숫자가 바뀔 때마다 `upsertMonthlySnapshot()` 이 **이번 달 줄을 덮어씁니다** — 이번 달 점은 늘 지금 상태를 따라갑니다
- 달이 바뀌면 지난달 줄은 그대로 **얼어붙습니다.** 지난 줄은 절대 손대지 않습니다
- 숫자가 그대로면 같은 배열을 돌려줘서 저장도 렌더도 헛돌지 않습니다

**추이** 탭은 최근 12개월을 SVG 선 그래프로 그립니다(차트 라이브러리 없음).
빈 달은 선을 끊고, 이번 달 점은 크게 찍습니다. `순자산` / `자산 / 부채` 두 모드가 있고,
아래 표에 달 · 금액 · **전월 대비**(+는 초록, −는 빨강)가 나옵니다.
홈의 순자산 아래에도 지난달 스냅샷이 있으면 `전월 대비 +820,000원 (+2.1%)` 한 줄이 뜹니다.

스냅샷이 둘 미만이면 "다음 달부터 추이가 보여요"만 띄웁니다. 백업 파일(버전 2)에도 같이 담깁니다.

### 평가액 이력 — 이 자산이 어떻게 움직였나

자산 편집 시트에서 **지금 얼마**를 고쳐 저장하면 `Asset.valueHistory` 에 `{ date, value }` 가 한 줄 쌓입니다 (`utils/history.ts`).

- 같은 날 두 번 고치면 마지막 값만 남고, 최대 120줄까지만 둡니다
- 이력이 없던 예전 기록은 **첫 저장 때** 마지막으로 고친 날의 평가액을 첫 줄로 깔아줍니다 (불러올 때 하지 않는 이유: 안 고친 기록의 `updatedAt` 까지 바뀌면 백업 병합이 꼬입니다)
- 편집 시트의 **평가액 이력**을 펼치면 줄마다 지울 수 있고, `returnSince()` 로 **첫 기록 이후**와 **한 달 전 대비** 수익이 보입니다.
  한 달 전 딱 그 날 기록이 없으면 그 이전 가장 최근 줄을 기준으로 씁니다
- 자산 탭 목록에는 이력이 두 줄 이상일 때 작은 추세선(60×16 SVG)이 붙습니다

### 만기 알림 — 캘린더로 내보내기

홈의 '다가오는 만기'(`summary.upcoming`: 자산 만기일 · 대출 종료일)를 **설정 → 만기 일정 캘린더로 내보내기 (.ics)** 로 받을 수 있습니다.
`utils/ics.ts` 의 `buildIcs()` 가 RFC 5545 형식으로 만듭니다.

- 항목마다 **종일 일정** 하나, `VALARM TRIGGER:-P7D` 로 **7일 전 알림**
- `UID` 는 자산·대출 id 로 고정 — 다시 내보내 가져와도 같은 일정이 두 개 생기지 않습니다
- 한글은 UTF-8 로 3바이트라 75옥텟 줄 접기를 글자 단위로 합니다
- 7일 안에 닥치는 만기가 있으면 홈의 만기 카드 맨 위에 노란 줄이 뜹니다

내려받은 `asset-dates.ics` 를 열면 아이폰·안드로이드·구글 캘린더에 그대로 들어갑니다.

## 대출 계산

`src/utils/loan.ts` 가 전부 계산합니다. 월이율 `i = 연이율 ÷ 100 ÷ 12`, 상환 개월 `n = 총기간 − 거치기간`.

| 상환 방식 | 매달 내는 돈 | 남은 원금 |
|---|---|---|
| **원리금균등** | `A = P·i ÷ (1 − (1+i)⁻ⁿ)` — 매달 같음 | `P·((1+i)ⁿ − (1+i)ʲ) ÷ ((1+i)ⁿ − 1)` |
| **원금균등** | 원금 `P/n` 고정 + 잔액×i — 갈수록 줄어듦 | `P − (P/n)·j` |
| **만기일시** | 이자 `P·i` 만 | 만기까지 `P` 그대로 |

**거치기간**은 원금을 그대로 두고 이자만 내는 기간입니다(전세자금대출에 흔함).
거치 중에는 남은 원금이 줄지 않고 월 상환액이 `P·i` 로 고정됩니다.

만기일시는 원금이 안 줄어서 '원금 상환률' 막대가 늘 비어 있으므로, 화면에서는 대신 **기간 경과율**을 보여줍니다.

무이자(`i = 0`)면 위 공식이 0으로 나눠지므로 따로 분기합니다.

### 중도상환했다면 — 직접 적기

중도상환을 하면 위 계산이 실제와 어긋납니다. 최초 원금을 낮춰봐야 거기서 또 갚은 만큼 빠져서 더 틀어집니다.
그래서 대출 편집 화면의 **지금 남은 원금 → [직접 적을게]** 로 은행 앱에 찍힌 잔액을 그대로 넣을 수 있습니다.

- `manualRemaining` 이 있으면 `loanStatus()` 는 계산을 통째로 건너뜁니다
- **적은 값은 저절로 줄지 않습니다.** 대신 `manualAsOf`(적은 날짜)를 카드에 같이 띄워 낡았는지 보이게 합니다
- 월 상환액도 적을 수 있습니다. 비우면 남은 원금을 남은 기간에 나눠 갚는 걸로 계산합니다
- 이때 '만기까지 총 이자'는 성립하지 않으므로 **앞으로 낼 이자**로 바뀝니다.
  계약 기간이 아니라 `payoffMonths(잔액, 월이율, 상환액)` — 실제 상환 속도로 계산합니다.
  상환액이 이자에도 못 미치면 영원히 안 끝나므로 `—` 로 표시합니다

## 데이터는 어디에

**이 브라우저의 localStorage에만 있습니다.** 서버로 아무것도 보내지 않습니다.

그래서 브라우저 데이터를 지우거나 폰을 바꾸면 **그대로 사라집니다.**
가끔 **설정 → 백업 파일로 내보내기**를 눌러 JSON 파일을 받아두세요. 이게 유일한 방어선입니다.

불러오기는 지금 기록 위에 **합칩니다**(`utils/merge.ts` 의 `mergeById`).
항목마다 `id` 와 `updatedAt` 이 있고 삭제도 툼스톤(`deleted: true`)으로 남기 때문에,
백업을 얹어도 지운 항목이 되살아나지 않고 더 최근에 고친 쪽이 남습니다.

폰에서 **공유 → 홈 화면에 추가**를 하면 앱 아이콘으로 열리고, 저장한 기록도 더 오래 남습니다.

### 오프라인 — 지하철에서도 열린다

`public/sw.js` 서비스워커가 앱 껍데기만 캐시합니다. 기록은 어차피 localStorage 에 있어서 서버가 필요 없습니다.

- 설치 때 `index.html` 과 CRA 빌드가 만든 `asset-manifest.json` 을 읽어 해시 붙은 JS/CSS 를 미리 담아둡니다
- `/static/` 은 캐시 먼저(파일명에 해시가 있어 내용이 안 바뀜), 페이지 이동은 네트워크 먼저 → 끊기면 캐시한 `index.html`
- 캐시 이름에 `VERSION` 이 들어갑니다. 캐시 동작을 바꾸면 올리세요. 활성화 때 이 앱의 옛 캐시만 지우고 같은 도메인의 다른 앱 캐시는 건드리지 않습니다
- `src/index.tsx` 가 **프로덕션 빌드에서만** `PUBLIC_URL/sw.js` 를 등록합니다 (`updateViaCache: 'none'` 이라 sw.js 자체는 늘 새로 받습니다). `npm start` 에서는 캐시가 코드 수정을 가리지 않게 등록하지 않습니다
- 설정 탭에 **오프라인 사용 가능 ✓** 가 뜨면 준비된 것입니다. 처음 연 직후엔 아직 안 떠 있을 수 있습니다 — 한 번 더 열면 됩니다

## 개발

```bash
cd asset-tracker
npm ci
npm start                      # http://localhost:3000
npm test -- --watchAll=false   # loan / summary / format / goal / merge / snapshot / history / ics / backup
npm run build
```

### 구조

```
src/
  App.tsx              # 탭 라우팅 + summarize()를 돌리는 useMemo 하나
  types/index.ts       # 도메인 타입과 상수 전부
  hooks/useAssets.ts   # localStorage CRUD (삭제는 툼스톤)
  components/          # 화면과 편집 시트. 전부 인라인 style
    TrendView.tsx      # 추이 탭 — SVG 선 그래프 + 전월 대비 표
    Sparkline.tsx      # 자산 목록의 작은 추세선
  utils/
    loan.ts     + .test # 대출 상환 계산
    summary.ts  + .test # 순자산·구성·만기 집계
    goal.ts     + .test # 목표 달성률
    snapshot.ts + .test # 월별 순자산 스냅샷 (만들기/덮어쓰기/전월 대비)
    history.ts  + .test # 자산 평가액 이력 (쌓기/수익률)
    ics.ts      + .test # 만기 일정 .ics 생성 (이스케이프·75옥텟 접기)
    backup.ts   + .test # 백업 파일 형식 (버전 2, 1도 읽힘)
    format.ts   + .test # 원/억/만원, D-day 표기
    date.ts             # 날짜 계산 (지역시각 기준)
    merge.ts, storage.ts, id.ts
public/sw.js           # 오프라인용 서비스워커 (앱 껍데기만 캐시)
```

**돈 계산은 반드시 `utils/` 의 순수 함수에 두고 `.test.ts` 를 같이 씁니다.**
'오늘'은 항상 인자로 주입해서 테스트가 시계에 의존하지 않게 합니다 — `couple-budget/src/utils/budget.ts` 와 같은 관행입니다.

컴포넌트는 계산하지 않습니다. `App.tsx` 의 `useMemo` 가 `summarize()` 를 한 번 돌리고 결과를 내려줍니다.

### 스타일

Tailwind도 CSS 모듈도 쓰지 않습니다. 전부 인라인 `style={{}}` 이고,
공유하는 값(카드·색·행·버튼)은 `src/components/ui.ts` 에 모여 있습니다.
`index.css` 는 리셋과 시트 애니메이션 두 개뿐입니다.
