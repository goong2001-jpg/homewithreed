# 산업안전기사 시험 대비 (safety-exam)

산업안전기사 **필기 CBT**를 실제 시험처럼 풀어 보고, 틀린 문제는 **오답노트**로 모아 다시 풀고,
**실기 필답형**은 플래시카드로 암기하는 앱입니다. 서버 없이 브라우저 `localStorage`에만 기록을 저장합니다.

안드로이드 크롬에서 열고 메뉴의 **"홈 화면에 추가"**를 누르면 앱처럼 전체화면으로 실행됩니다.

배포 주소: `https://<계정>.github.io/homewithreed/safety-exam/`

---

## 화면

| 화면 | 하는 일 |
|---|---|
| ⚡ **10문제 간이시험** | 여러 과목에서 10문제만 골라 10분 안에 풀기 · 마지막 문제까지 풀면 바로 채점과 해설 · 틀린 문제는 오답노트에 자동 저장 |
| 📝 **필기 CBT 모의고사** | 6과목 × 20문제, 180분 타이머 · 과목별 점수와 합격 여부(평균 60점 이상 & 전 과목 40점 이상) |
| 📕 **오답노트** | 모의고사·간이시험에서 틀린 문제를 모아 다시 풀기 · 맞히면 목록에서 지울 수 있음 |
| 🗂️ **실기 필답형 대비** | 기출 유형 필답형 문제를 플래시카드로 넘기며 셀프 채점 · 모르는 문제만 반복 |
| ➕ **문제 추가/관리** | 기출문제를 직접 입력하거나 JSON 파일로 올려 나만의 문제은행 넓히기 |

제목(🦺 산업안전기사 시험 대비)을 누르면 언제든 홈으로 돌아갑니다.

## 시험 진행

- 남은 시간은 **마감 시각** 기준으로 계산하므로 화면을 끄거나 다른 앱에 갔다 와도 어긋나지 않습니다.
- 답을 고를 때마다 **풀던 시험이 저장**됩니다. 시험 종료나 새로고침 뒤 같은 시험을 다시 열면
  문제·보기 순서·답안·남은 시간이 그대로 이어집니다. (마감이 지난 시험은 버립니다)
- 보기 순서는 문제마다 **매번 섞여** 나옵니다. 번호를 외우는 대신 내용을 보고 고르도록 하기 위한 것입니다.
- 풀던 시험을 나갈 때는 확인 창이 한 번 뜹니다.

## 문제 데이터

- 내장 필기 문제는 `src/data/written/`, 실기 문제는 `src/data/practicalQuestions.ts`에 있습니다.
- 직접 추가한 문제는 `localStorage`에 저장되며, 시험지는 내장 + 추가 문제를 합쳐 만듭니다.
- JSON 업로드 형식은 **문제 추가/관리** 화면의 템플릿을 참고하세요.

## 개발

```bash
npm run build
```
