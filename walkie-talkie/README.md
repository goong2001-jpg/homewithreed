# 집무전기 (walkie-talkie)

폰 마이크와 스피커만으로 쓰는 **PTT(누르고 말하기) 무전기** PWA입니다.
같은 **채널 번호 4자리**를 넣은 사람끼리 최대 6명이 연결되고, 큰 버튼을 누르는 동안만 목소리가 나갑니다.

* 서버 없음 — 음성은 브라우저끼리 직접(WebRTC P2P) 오갑니다. 통화료·서버비 0원.
* 설치 없음 — 주소만 열면 됩니다. 홈 화면에 추가하면 앱처럼 씁니다.
* 가입 없음 — 이름과 채널 번호만.

## 쓰는 법

1. 두 사람 다 같은 주소를 엽니다.
2. 이름과 **똑같은 채널 번호 4자리**를 넣고 `채널 열기`.
3. 마이크 권한 허용 → 상대가 들어오면 상단에 이름이 뜹니다.
4. 가운데 큰 버튼을 **누르고 있는 동안** 말이 전달됩니다. (PC는 스페이스바)

옵션 두 가지가 있습니다.

| 옵션 | 설명 |
|---|---|
| 손 떼도 계속 송신 | 버튼을 토글로 바꿉니다. 운전 중처럼 손을 못 쓸 때. |
| 말하는 동안 상대 소리 줄이기 | 스피커폰 하울링을 막습니다. 기본 켜짐. |

## 아는 한계 (중요)

* **백그라운드 수신이 안 됩니다.** 브라우저를 닫거나 다른 앱으로 나가면, 특히 아이폰은 화면을 끄면
  연결이 끊깁니다. 화면을 켜둔 채로 쓰는 용도입니다. (화면 자동 꺼짐은 앱이 막아줍니다.)
  진짜 "폰이 꺼져 있어도 삐- 하고 상대 목소리가 나오는" 무전기는 iOS `PushToTalk` 프레임워크가 필요하고,
  이건 앱스토어 네이티브 앱 + Apple 승인(VoIP entitlement)이 있어야 합니다.
* **스피커/이어폰 전환을 앱이 고를 수 없습니다.** 웹은 출력 장치를 강제하지 못합니다.
  이어폰이 꽂혀 있으면 이어폰으로, 아니면 스피커로 나갑니다.
* **채널 번호를 아는 사람은 누구나 들어옵니다.** 암호가 아닙니다. 통신 자체는 WebRTC라 암호화되지만
  방 번호는 비밀번호가 아니라는 뜻입니다. 남들이 안 쓸 번호를 쓰세요.
* **가끔 연결이 안 될 수 있습니다.** 이동통신망끼리는 직접 연결이 막혀 중계(TURN) 서버를 타는데,
  지금은 무료 공개 서버를 씁니다. 자주 끊기면 `app.js`의 `ICE` 값을 유료/자체 TURN으로 바꾸세요.

## 구조

빌드가 필요 없는 정적 파일입니다.

```
index.html   화면
app.js       PTT·연결 로직 (PeerJS CDN 사용)
style.css    스타일
sw.js        오프라인 껍데기 캐시
manifest.json / icon*  PWA 설치용
```

연결 방식: 채널 `1234`이면 `hwr-wt-1234-1` ~ `hwr-wt-1234-6` 여섯 개의 ID 중 빈 자리를 차지하고,
나머지 다섯 자리에 전부 전화를 겁니다(메시 구조). 별도 시그널링 서버 없이 PeerJS 공개 브로커만 씁니다.

## 로컬에서 보기

마이크는 `https` 또는 `localhost`에서만 열립니다.

```bash
cd walkie-talkie
npx serve .        # 또는 python3 -m http.server 8000
```

폰끼리 시험하려면 GitHub Pages에 올라간 https 주소로 접속하세요.

## 자동 테스트

가짜 브로커(`test/fakepeer.js`)를 끼워 넣고 탭 두 개를 띄워, 입장 → 서로 인식 → PTT 송신 →
퇴장까지를 확인합니다. 실제 인터넷 연결 없이 로직만 검증합니다.

```bash
cd walkie-talkie
npx http-server -p 8137 -s .          # 다른 터미널에서
npx playwright install chromium       # 처음 한 번
node test/smoke.js
```

확인하는 것: 슬롯 차지, 빈 슬롯이 인원수에 섞이지 않는지, 이름 교환, 송신 표시 전파,
퇴장 시 목록 정리, 콘솔 오류 없음.
