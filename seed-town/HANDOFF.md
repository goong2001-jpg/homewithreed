### v2 설계 (각 단계가 무엇을 더 보여 주나)

모든 단계는 **같은 세계·같은 엔진**을 쓴다. 프로필의 `stage`(seed → sprout → tree → forest)에 따라 화면이 여는 정보만 늘어난다. 단계는 어른 메뉴에서 바꾸고, 바꿔도 마을·기록은 그대로다.

| 단계 | 추가로 열리는 것 | 읽기 훈련 | 스승 배지 |
|---|---|---|---|
| 새싹 | 씨앗 값(= 주가)과 변화 화살표·그래프 / 성적표 3줄: 번 돈·쓴 돈·남은 돈 / 절반 꺼내기 | 소식을 맞힌 뒤 "성적표의 어느 줄이 바뀔까?(번 돈/쓴 돈)" | 린치 — 성적표를 보고 나서 심기 5번 |
| 나무 | 손익계산서·재무상태표·현금흐름표 / PER·ROE·부채비율·배당수익률 / 용어를 실제 말로(주식·주가·배당) | 공시 카드: 유상증자·자사주 소각·대주주 매도·실적 발표 / 위기 카드 3장(1997 외환위기·2008 금융위기·2020 코로나) | 그레이엄 — PER 이 낮을 때 사기 |
| 숲 | 공시 원문 형식의 분기보고서(가게 장부에서 자동 생성) / 투자일지(살 때·팔 때 이유 적기) / 복기(4계절 뒤 그 판단이 맞았나) | 원문을 읽고 푸는 문제 3개(이익률·부채비율·배당성향 등) | 멍거 — 이유를 적고 사기 5번 |

구현 메모
- 엔진: 가게마다 `shares`(주식 수)를 따로 둔다(유상증자·소각 때문). `hist` 에 변동비·고정비·이자·재투자·빌린 돈·갚은 돈·자산·주식 수를 더 적는다. 예전 저장분은 그 칸이 없으니 화면에서 0 으로 본다.
- 공시 카드는 `NEWS` 에 `stage: 'tree'` 를 달고, 효과는 `sharesMul`(주식 수 배수)·`cashAdd`(들어오는 돈)·`priceMul`(값만 잠깐 움직임) 로 적는다.
- 소식 카드는 플레이어 단계 이하의 것만 나온다(`drawNews`).

## 1. 왜 만드나

- **최종 목표**: 구름(첫째 딸, 지금 7살)이 성인이 됐을 때 공시·재무제표·뉴스를 읽고 스스로 판단하는 투자자가 되는 것. 아빠(묘사)도 같이 실력을 쌓는다.
- **요청 원문 요약**: 7살 아이가 커 가면서 투자 공부를 할 수 있는 게임. 나이가 들수록 더 실전처럼 되는 기반틀. 투자 고수들은 어떻게 했는지. 재무제표·공시·뉴스 읽는 법을 게임처럼. 영유아·초등·청소년·성인이 같이.
- **초점(지금 가장 중요한 변수 1개)**: 구름이가 2주 뒤에도 **스스로** 여는가. 이게 안 되면 나머지 단계는 의미가 없다.

### v3 에서 더 된 것 — 세계 단계 (2026-11-15, 미배포)

- 다섯 번째 단계 `world`("세계"). 어른 메뉴 → 단계 고르기. 마을 화면 아래에 `실제 회사 책장` 단추가 생긴다(숲 단계 기능은 그대로 다 쓴다)
- **넣는 법**: 회사 이름·기간·자료 종류(1년치/분기)·금액 단위(원/백만원/억원)를 고르고, 숫자를 칸에 직접 적거나 재무제표 글을 붙여넣은 뒤 `붙여넣은 글에서 숫자 찾기`. 꼭 필요한 칸은 매출액·당기순이익·부채총계·자본총계 4개
- **넣으면 적용되는 것**(전부 `engine.analyze` 가 그 숫자로 계산): 비율 8개(영업이익률·순이익률·ROE·부채비율·PER·PBR·배당성향·배당수익률), 점검표 5줄(① 흑자 ② 빚 ③ 영업현금 + 그레이엄 PER×PBR≤22.5 + ROE 15%), 그 숫자로 만든 문제 3개(`makeRealQuiz`), 앞 기간 대비 매출·순이익 변화
- **예측과 복기**: 회사마다 "다음 기간 순이익이 늘어난다/비슷하다/줄어든다(±5%)"와 이유를 걸어 두고, 다음 기간 숫자를 넣으면 채점(`saveReal`). 배지 「세계로」「복기하는 투자자」
- 글 읽기(`parseStatement`)는 항목 이름 뒤 **그 줄의 첫 숫자**를 가져온다. `(1,234)`·`△1,234` 는 음수. 항목 이름 목록은 `data.js` 의 `REAL_FIELDS[].find`
- 저장: 프로필의 `P.real = [{ name, periods: [{ label, quarter, unit, v }], pred, reviews }]`. 기기에만 저장
- 테스트: 엔진 32개 + 화면 40개 항목 통과. 버전 `?v=3`, `sw.js` 캐시 v3, `version.json` 3

세계 단계의 한계
- 숫자는 사람이 옮긴다. DART 자동 불러오기·시세 연동 없음(서버 없는 구조라 넣지 않았다. 하려면 DART 오픈API 키와 중계 서버가 필요)
- 글 읽기는 "항목 숫자"가 한 줄에 있는 단순한 글만 된다. 표를 복사했을 때 줄이 깨지면 직접 적어야 한다. 단위·기간(당기/전기)을 잘못 읽을 수 있어 화면에 "원문과 맞는지 확인" 안내를 넣었다
- 실제 회사는 마을에서 사고팔 수 없다(가격이 없어서). 읽기·점검·예측·복기만 한다
- 점검 기준(그레이엄 22.5, ROE 15%)은 책에서 흔히 인용되는 참고 기준이라 업종별로 맞지 않을 수 있다. 화면에 안내 문구 있음
- 연결/별도, 지배주주 순이익, 금융업 특수 계정 구분 없음

### v5 에서 더 된 것 — 길잡이와 도움말 (2026-11-15)

- **길잡이(튜토리얼)**: 씨앗·새싹 단계에서 처음 한 번. 말풍선이 한 걸음씩 알려 주고, 눌러야 할 곳이 주황 테두리로 반짝이고, 글을 읽어 준다. 걸음은 `data.js` 의 `TUTORIAL`(10걸음: 소식 고르기 → 빵집 누르기 → 동전 심기 → 새싹 설명 → 나눠 심고 계절 넘기기 → 얼굴 설명 → 두 번째 소식 → 가게 밑 숫자 → 마을 보물 → 물음표 안내)
- 아이가 그 걸음에서 기다리던 일을 하면 다음으로 넘어간다(`app.js` 의 `tutEvent`). 순서를 건너뛰어도 3걸음 안이면 따라온다. "설명 그만 보기"로 끌 수 있다
- 새 프로필의 첫 소식은 늘 쉬운 카드(빵집 새 오븐)로 시작한다
- **열매 첫 안내**: 처음 열매가 익었을 때 "따기" 설명이 한 번 뜬다(`P.tipFruit`)
- **물음표(?) 도움말**: 씨앗·새싹 단계 오른쪽 위. 동전·새싹과 나무·열매·얼굴·숫자·소식과 소문·나눠 심기·꺼내기·마을 보물 설명(`data.js` 의 `HELP`), 항목마다 "들려줘", "처음부터 다시 배우기"
- **계절 제한 없음**: `RULES.turnsByStage` 가 모두 0. "오늘은 여기까지" 화면은 더 안 나오고, 대신 4계절마다 결과 창에 "N년이 지났어요. 마을 보물 A → B" 한 줄이 뜬다
- 저장: 프로필의 `P.tut`(걸음 번호 또는 'done'). 기존 씨앗·새싹 프로필은 길잡이가 처음부터 한 번 나온다
- 테스트 87개 통과. 버전 `?v=5`

### v6 에서 더 된 것 — 내 선택의 결과 (2026-11-15)

- **계절 결과 창**: 내가 심은 가게가 맨 위. 가게마다 `내 나무 3 → 4 ▲1 · 열매 +1`, 그 계절 소식이 그 가게 것이면 "(소식 때문이에요)"
- **내 선택의 결과 상자**: "내가 심은 가게에서 동전이 N개 생겼어요/줄었어요" + 막대 2개(**그냥 뒀다면** = 처음 동전 + 심부름 동전 합계 / **심은 지금** = 마을 보물) + "가게에 심어서 지금까지 N개 더 생겼어요". 계산은 `engine.nextTurn` 의 `out.mine`
- **왜 할까요 한 줄**(씨앗·새싹): 소식 창 "왜 소식을 볼까요?", 가게 창 "왜 심을까요?" (`data.js` 의 `TEXT.why`)
- **사람 바꾸기**: 왼쪽 위 이름 단추를 누르면 "누가 할까요" 화면으로 나간다(어른 메뉴를 거치지 않아도 됨)
- 테스트 90개 통과. 버전 `?v=6`

### 알고 있는 한계 (고치려면 여기부터)

- 게임 속 PER(2~3배)·배당수익률(20% 안팎)은 실제와 크게 다르다. 씨앗 단계에서 열매가 자주 보이도록 `RULES.shares` 를 작게 잡은 탓. 나무·숲에서 실제 감각을 주려면 **단계별로 표시 배율을 따로 두거나**(예: 숲은 1계절=1년으로 환산해 표시) 가게 수치를 손봐야 한다
- 공시 카드의 정답은 "보통 그렇다" 수준의 단순화다(유상증자=나쁨, 소각=좋음, 대주주 매도=알 수 없음). 풀이 글(`explain`)에 단서를 달아 두었다
- 분기보고서는 실제 DART 서식을 **본뜬** 연습 문서다. 실제 공시 원문(주석, 사업의 내용, 감사의견 등)은 아직 없다
- 새싹의 "주 1회 장날", 나무의 "분기 단위" 같은 플레이 주기는 넣지 않았다. 모든 단계가 하루 4계절 제한을 같이 쓴다
- 실제 폰에서의 음성 읽기·홈 화면 추가는 확인하지 못했다

## 5. 중단 기준 · 리스크

- **중단 기준**: 샘플을 준 뒤 2주 동안 구름이가 스스로 여는 횟수가 **주 2회 미만**이면 씨앗 단계는 보류하고, 아빠용 숲 단계(공시 읽기 훈련)만 남긴다. 어른 메뉴 → 관찰 기록에서 센다.

- 기회비용: 이직 준비 시간을 잠식하지 않게, 아빠 시간은 "관찰"에만 쓴다.
- 대안(작게 가는 길): 새 앱 대신 `family-bank` 에 "가게에 맡기기" 탭만 추가.
