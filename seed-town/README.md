# 씨앗 마을 (seed-town)

가게에 동전을 심고, 계절이 지나길 기다리고, 열매를 따면서 **투자를 배우는 가족 게임**입니다.
아이가 커 가면서 같은 마을이 점점 실전처럼 바뀌도록 만든 기반틀이고, **씨앗(5~7세) → 새싹(초등) → 나무(청소년) → 숲(성인) → 세계(실전)** 다섯 단계가 있고, 어른 메뉴에서 사람마다 단계를 고릅니다.

기획·결정사항·로드맵·다음 할 일은 [`HANDOFF.md`](HANDOFF.md) 에 있습니다. **이어서 작업할 때는 그 파일부터 읽습니다.**

서버 없이 이 기기 브라우저 `localStorage` 에만 저장합니다. 안드로이드 크롬에서 열고 **"홈 화면에 추가"** 하면 앱처럼 실행됩니다.
배포 주소: `https://<계정>.github.io/homewithreed/seed-town/`

## 단계 (v2)

같은 마을, 같은 가게를 보지만 단계가 오를수록 더 많은 숫자가 열립니다. 처음 시작할 때 구름·열매는 씨앗, 아빠·엄마는 세계 단계로 잡히고(처음 화면에서 바꿀 수 있음), 씨앗은 하루 4계절·새싹은 8계절까지, **나무·숲·세계는 하루 제한이 없습니다.** `어른` 메뉴 → **단계 고르기**에서 바꾸고, 바꿔도 마을과 기록은 그대로입니다.

| 단계 | 더 보이는 것 | 읽기 훈련 | 스승 배지 |
|---|---|---|---|
| 씨앗 (5~7세) | 가게 그림 · 동전 · 열매 | 소식이 좋은지 나쁜지, 소문은 "아직 몰라요" | 보글 · 버핏 · 템플턴 |
| 새싹 (초등) | 씨앗 값과 값 그래프 · 성적표 3줄(번 돈·쓴 돈·남은 돈) · 절반 꺼내기 | 소식이 성적표의 어느 줄(번 돈/쓴 돈)을 바꾸는지 | 린치 — 성적표를 보고 나서 심기 |
| 나무 (청소년) | 재무제표 3표 · PER·ROE·부채비율·배당수익률 · 말이 주식·주가·배당으로 바뀜 | 공시 카드(유상증자·자사주 소각·대주주 매도·실적) · 위기 카드(1997·2008·2020) | 그레이엄 — 평소 값보다 20% 넘게 쌀 때 사기 |
| 숲 (성인) | 분기보고서 형식의 문서 · 투자일지 · 복기 | 보고서를 읽고 순이익률·부채비율·배당성향 계산 | 멍거 — 이유를 적고 사기 |
| 세계 (실전) | **실제 회사** 재무제표를 넣는 책장 · 비율 8개 · 점검표 | 진짜 숫자로 문제 풀기 · 다음 실적 예측과 복기 | 그레이엄·버핏의 기준으로 점검 |

- **재무제표**: 가게 창 → `재무제표 3표 보기`. 손익계산서·재무상태표·현금흐름표가 가게의 실제 장부에서 나옵니다.
- **공시 읽기**: (숲) 가게 창 → `분기보고서 읽고 문제 풀기`. 가게마다 계절에 한 번, 맞힌 만큼 별.
- **투자일지**: (숲) 가게 창에서 이유를 적고 사거나 팔면 남습니다. 마을 화면 아래 `투자일지 · 복기`에서 4계절 뒤 판단이 맞았는지 봅니다.
- 게임 속 수익률·PER 은 열매가 자주 보이도록 실제보다 크게(싸게) 잡혀 있습니다. 숫자의 **크기**가 아니라 **읽는 법**을 익히는 용도입니다.

## 세계 단계 — 실제 재무제표 넣기 (v3)

1. `어른` → 단계 고르기 → **세계**. 마을 화면 아래 `실제 회사 책장`을 누릅니다.
2. `새 회사 넣기` → 회사 이름, 기간(예: 2025년), 자료 종류(1년치/분기), 금액 단위(원/백만원/억원)를 고릅니다.
3. 숫자를 넣습니다. 두 가지 방법이 있습니다.
   - 칸에 직접 적기 (손실은 `-` 를 붙임)
   - 전자공시(DART)·증권 앱의 재무제표 글을 복사해 붙여넣고 `붙여넣은 글에서 숫자 찾기`. `매출액 1,200`처럼 항목 이름과 숫자가 한 줄에 있어야 하고, 그 줄의 첫 숫자를 가져옵니다. **찾은 값은 원문과 꼭 대조하세요.**
4. 꼭 필요한 칸은 매출액·당기순이익·부채총계·자본총계입니다. 주가·발행주식수까지 넣으면 PER·PBR 이, 영업활동현금흐름을 넣으면 현금 점검이, 배당금총액을 넣으면 배당 비율이 나옵니다.
5. `저장하고 분석 보기` → 그 숫자로 **점검표 5줄**(① 흑자인가 ② 빚이 감당할 만한가 ③ 장사로 현금이 들어오는가 + 그레이엄·버핏의 눈), **비율 8개**, **문제 3개**가 만들어집니다.
6. `다음 기간 순이익은?` 에 예측과 이유를 걸어 두고, 나중에 `다음 기간 숫자 넣기`를 하면 예측이 채점됩니다.

숫자는 이 기기에만 저장됩니다. 공부용이며 특정 회사를 사라는 뜻이 아닙니다. 점검 기준은 책에서 흔히 인용되는 참고 기준이라 업종마다 다를 수 있습니다.

## 노는 법 (씨앗 단계)

1. **누가 할까요** — 구름·열매·아빠·엄마 중에 고릅니다. 사람마다 마을이 따로 있습니다.
2. **오늘의 소식** — 계절마다 소식이 하나 옵니다. 그 가게에 좋은 소식인지 나쁜 소식인지 고릅니다. 맞히면 별 1개. 2년이 지나면 "~라는 소문이 있어요" 카드가 섞이고, 그때 정답은 **아직 몰라요**입니다.
3. **동전 심기** — 가게를 누르고 동전을 심으면 그 가게의 주인 중 한 명이 됩니다. 가게 옆에 내 나무가 자랍니다.
4. **다음 계절로** — 가게마다 장사가 잘됐는지(웃는 얼굴), 보통인지, 힘들었는지(우는 얼굴)가 나옵니다. 잘된 가게는 나무에 열매를 맺습니다.
5. **열매 따기** — 익은 열매를 누르면 동전이 됩니다. 다시 심을 수 있습니다.
6. **하루에 1년** — 계절 4개를 넘기면 "오늘은 여기까지". 다음 날 다시 열립니다.

가게 밑 `2 → 5` 는 "내가 넣은 동전 2개가 지금 5개가 됐다"는 뜻입니다.
마을 보물(가진 동전 + 나무 값)이 늘면 마을에 꽃밭·그네·분수·풍차·무지개·열기구·시계탑이 생깁니다.

### 가게 6곳

| 가게 | 성격 |
|---|---|
| 솔솔 빵집 | 꾸준함. 열매를 많이 나눠 줌 |
| 달콤 과일가게 | 여름에 잘됨 |
| 반짝 장난감 | 겨울에 아주 잘되지만 빚이 있고 들쭉날쭉. **가끔 문을 닫음** (심은 씨앗이 사라짐 → 나눠 담기를 배우는 곳) |
| 씽씽 자전거 | 열매는 적지만 번 돈으로 가게를 키움 |
| 별빛 책방 | 조용하고 늘 그대로. 열매를 가장 많이 나눠 줌 |
| 눈꽃 아이스크림 | 여름엔 최고, 겨울엔 손해 |

### 어른 메뉴

오른쪽 위 `어른` → 곱셈 문제를 풀면 들어갑니다.

- **관찰 기록**: 날짜별 플레이. 날짜를 눌러 "스스로 열었는지" 표시
- **아이와 나눌 한마디**: 방금 받은 배지에서 나온 질문
- **배지**: 배지마다 배운 것, 스승(보글·버핏·템플턴)의 원칙과 출처
- **장부 엿보기**: 아이에게는 안 보이는 가게의 실제 장부(판 돈·쓴 돈·남은 돈·나눠 준 돈·가진 돈·빚·씨앗 값)
- **설정**: 읽어 주기·소리, 오늘 한 해 더 열기, 다른 사람으로 바꾸기, 백업 글 만들기·되돌리기, 처음부터

## 고치는 법

**내용과 숫자는 `data.js` 만 고치면 됩니다.**

| 바꾸고 싶은 것 | 고칠 곳 (`data.js`) |
|---|---|
| 처음 동전, 계절마다 받는 동전 | `RULES.startCoins`, `RULES.allowance` |
| 하루에 넘길 수 있는 계절 수 | `RULES.turnsPerDay` |
| 열매가 열리는 빠르기 | `RULES.shares` (작을수록 자주), `RULES.welcomeFruit` |
| 가게가 문 닫는 정도 | `RULES.closeDebt`, 가게의 `debt`·`vol` |
| 소문이 나오기 시작하는 때 | `RULES.rumorFrom` |
| 가게 추가·성격 바꾸기 | `SHOPS` (모양 `shape`: tri·awning·flat·dome, 간판 `sign`: bread·apple·star·wheel·book·cone) |
| 소식 카드 추가 | `NEWS` |
| 배지·대화 질문 | `BADGES` |
| 마을에 생기는 것 | `WISHES` (새 그림은 `app.js` 의 `skySvg`) |
| 스승 | `MENTORS` |

고친 뒤에는 `index.html` 의 `?v=4`, `sw.js` 의 `CACHE`·`SHELL`, `version.json` 숫자를 같이 올려야 폰에서 새 버전이 뜹니다.

## 구조

- `engine.js` — 규칙. 가게마다 계절별 장부(매출 → 비용 → 이익 → 배당 → 재투자 → 빚)를 돌리고, 최근 1년 이익으로 씨앗 값을 정합니다. 화면 없이 node 에서도 돕니다.
- `app.js` — 화면. 가게·나무·얼굴·동전은 전부 코드(SVG)로 그립니다.
- 단계(씨앗 → 새싹 → 나무 → 숲)가 올라가도 엔진은 하나이고, 단계는 **무엇을 보여 주느냐**만 다릅니다.
