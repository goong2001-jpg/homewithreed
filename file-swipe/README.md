# 스와이프 정리 (file-swipe)

갤럭시 폰의 사진·캡처·받은 파일을 **한 장씩 넘기며 표시**하고,
옮기기·삭제는 홈 화면에서 **한 번에 직접** 하는 안드로이드 앱입니다.

| 손짓 | 하는 일 |
|---|---|
| ↑ 위로 | 보관 — 분류(증빙 / 작업물 / 메모)를 고름 |
| ↓ 아래로 | 삭제 대기 — 바로 지우지 않음 |
| ← 왼쪽 | 이전 파일 |
| → 오른쪽 | 그대로 두고 다음 |
| 탭 | 다른 앱으로 크게 열기 |

* 넘기는 동안에는 **기록만** 합니다. 파일은 그대로입니다.
* 홈 › 정리 대기에서 `옮기기`를 누르면 `내장 저장공간/파일정리/분류이름` 으로 옮겨집니다.
  갤러리에는 그 이름의 앨범으로 보입니다.
* `휴지통으로`를 누르면 `파일정리/.휴지통` 으로 옮겨집니다(갤러리엔 안 보임).
  `되살리기`로 원래 폴더에 돌아가고, `비우기`를 눌러야 실제로 지워집니다.
* 폴더마다 **어디까지 봤는지 기억**합니다. 앱을 닫았다 열면 홈 맨 위 `이어서 하기`로 이어집니다.

## 설치 (처음 한 번)

1. 폰 크롬에서 이 주소를 엽니다.
   `https://github.com/goong2001-jpg/homewithreed/releases/download/file-swipe/file-swipe.apk`
2. 받은 파일을 누르면 “이 출처의 앱 설치 허용”을 묻습니다 → 크롬 허용 → 설치.
3. 앱을 열고 `권한 허용하러 가기` → **모든 파일 접근** 켜기 → 뒤로 가기.

Play 프로텍트가 “알 수 없는 앱”이라고 경고할 수 있습니다. 직접 만든 앱이라 그렇습니다. `그래도 설치`.

## 업데이트

새 버전이 올라오면 앱 홈 맨 위에 `새 버전 받기` 버튼이 뜹니다(12시간마다 확인).
눌러서 받은 APK를 설치하면 **기록을 유지한 채** 덮어 설치됩니다.

## 고치고 배포하는 흐름 (Claude가 처리)

```
file-swipe/ 코드 수정 → 푸시
  → GitHub Actions(file-swipe APK)가 빌드
  → 릴리스 'file-swipe' 에 file-swipe.apk 덮어쓰기 (버전 = 실행 번호)
  → 앱이 새 버전 감지 → 폰에서 받기 → 설치
```

* 빌드 설정: `.github/workflows/file-swipe.yml`
* 서명 키는 저장소에 두지 않고 GitHub Secret 두 개에서 읽습니다.
  `FILE_SWIPE_KEYSTORE`(키 파일 base64), `FILE_SWIPE_KEY_PASSWORD`(비밀번호).
  * Secret이 있으면 → 매번 같은 키 → 새 버전을 **덮어 설치**할 수 있습니다.
  * Secret이 없으면 → 빌드마다 임시 키 → 업데이트 때 **앱을 지우고 다시 설치**해야 합니다.
* 어느 쪽이든 기록은 `파일정리/.앱기록.json` 에도 저장되어, 다시 설치해도 이어집니다.

## 코드 구조

| 파일 | 역할 |
|---|---|
| `MainActivity.kt` | 홈: 이어서 하기, 정리 대기, 휴지통, 폴더 목록, 설정 |
| `SwipeActivity.kt` | 넘기기 화면: 손짓·되돌리기·이어보기 |
| `ListActivity.kt` | 정리 대기·휴지통 바둑판 |
| `Repo.kt` | 폰 파일 목록(MediaStore 읽기)과 폴더 묶음 |
| `Store.kt` | 기록 저장(`state.json`): 표시, 진행 위치, 휴지통 목록 |
| `Ops.kt` | 실제 옮기기·휴지통·되살리기·비우기 |
| `Thumbs.kt` | 사진·영상·PDF 미리보기 |
| `Updater.kt` | GitHub 릴리스로 새 버전 확인 |

## 아는 한계

* 안드로이드 11 이상만 됩니다(갤럭시 S21 / 2021년 이후 대부분).
* 카카오톡 대화방 안에서 **저장하지 않은 파일**은 보이지 않습니다(카톡 내부 폴더는 다른 앱이 못 봄).
* 한글(HWP)·워드·엑셀은 미리보기 없이 이름과 확장자만 보입니다. 탭하면 해당 앱으로 열립니다.
* SD카드 파일은 목록에는 나오지만 탭해서 열기가 안 될 수 있습니다.
