# 일본어 한 걸음 (japanese-learn)

레벨테스트로 시작 단원을 정하고, **초급 → 중급 → 상급** 커리큘럼을 하루 한 단원씩
**단어 → 문형 → 퀴즈** 순서로 익히는 어른용 일본어 앱입니다.
구름이 영어 단어(kumon-math)와 같은 흐름(카드로 보고 듣기 → 4지선다 → 틀린 문제는 다시)을
어른 눈높이에 맞춰 옮겼습니다.

빌드 없는 정적 앱이라 폴더 그대로 GitHub Pages 에 올라갑니다.
배포 주소: `https://<계정>.github.io/homewithreed/japanese-learn/`
안드로이드 크롬 메뉴의 **홈 화면에 추가**를 누르면 앱처럼 전체화면으로 열립니다.

## 화면

| 탭 | 하는 일 |
|---|---|
| **今 오늘** | 오늘의 단원(第N課) 한 개, 복습할 단어 수, 이번 주 학습한 날 |
| **道 커리큘럼** | 레벨별 단원 목록. 완료 점수·지금 단원·건너뛴 단원 표시, 아무 단원이나 눌러 학습 |
| **復 복습** | 간격 복습(1·3·7·14·30일), 기억 상자 분포, 오답 노트와 오답만 다시 풀기 |
| **記 기록** | 학습한 날·연속·익힌 단어·완료 단원, 최근 4주, 레벨테스트 결과, 설정 |

## 레벨테스트 (최대 18문항)

초급 6 → 중급 6 → 상급 6. 한 단계에서 **4개 이상** 맞혀야 다음 단계로 갑니다. 모르면 **모르겠어요**.

| 결과 | 시작 단원 |
|---|---|
| 초급 3개 이하, 가나 문제 틀림 | 초급 1과 히라가나 |
| 초급 3개 이하, 가나 문제 맞힘 | 초급 3과 자기소개 |
| 초급 통과, 중급 0~1개 | 초급 6과 동사 ます형 |
| 초급 통과, 중급 2~3개 | 중급 1과 |
| 중급 통과, 상급 0~2개 | 중급 4과 사역형 |
| 상급 3개 이상 | 상급 1과 |

결과 화면에서 **한 단계 아래**로 시작할 수도 있습니다. 시작점보다 앞 단원은 "건너뜀"으로 표시되고 커리큘럼 탭에서 언제든 할 수 있습니다.

## 커리큘럼 (22단원 · 단어 252개 · 문형 20개)

- **초급 (JLPT N5~N4) 10단원**: 히라가나, 가타카나, 자기소개, 이것·저것, 시간, ます형, 형용사, 있다·없다, て형 부탁, 과거·경험
- **중급 (JLPT N3) 6단원**: ようにする/なる, たら·ば·なら, 수동, 사역, 경어, はず·わけ
- **상급 (JLPT N2~N1) 6단원**: にもかかわらず, に限らず·ばかりか, ざるを得ない, をきっかけに, とは限らない, 비즈니스 메일

단원마다 단어 8개 + 문형 1개(예문 3개) + 퀴즈 10문제(뜻·일본어·읽기·듣기·문형 빈칸).
가나 단원은 오십음도 표 + 10문제. **첫 시도 정답 70% 이상**이면 단원 완료, 단어가 다음 날부터 복습에 들어갑니다.
내용은 `data.js` 한 파일에 있어 단원을 더하거나 고치기 쉽습니다.

## 소리

브라우저 음성 합성으로 기기의 일본어(ja-JP) 음성을 씁니다. 일본어 음성이 없으면 듣기 문제는 자동으로 빠지고,
기록 탭에 음성 설치 방법이 나옵니다.

## 테스트

```bash
cd japanese-learn
python3 -m http.server 8141 &
node test/smoke.js     # playwright 필요
```

기록은 브라우저 `localStorage`(`hwr-jp-v1`)에만 저장됩니다(서버 없음).
배포할 때마다 `app.js` 의 `APP_VERSION`, `index.html` 의 `?v=`, `sw.js`, `version.json` 을 같이 올립니다.
