# 써브텍 주문앱

카톡 발주 메시지를 붙여넣으면 주문으로 나눠 저장하고, CJ·경동·대신 송장 엑셀과 하루 출하서(출고현황)를 뽑는 사무실용 웹앱입니다.
Google Apps Script 웹앱 + 재고 스프레드시트의 `주문…` 탭. 폰·PC 모두 사용.

## 쓰는 법
1. **새 주문** — 카톡 메시지를 복사해 붙여넣고 `나누기`. (PC 카톡에서 여러 메시지를 한꺼번에 복사해도 되고, 폰 대화 내보내기 글도 됩니다) 나눠진 카드를 눌러 고치고 `저장`.
   - 주소가 없는 단골은 주소록에서 채웁니다. 배송방법이 없으면 지난번 배송방법을 씁니다.
   - 노란 표시(주소 없음·배송방법 없음 등)는 송장 뽑기 전에 채워주세요.
2. **주문** — (주문 창에서 받는 곳은 최근 보낸 곳·주소록에서 고르거나 새로 입력해 주소록에 저장, 보내는분은 써브텍·지난번·거래처·직접 입력 중 선택) 대기(출고 예정별로 묶임)·출고완료 목록. 눌러서 고치기 / **출고**(날짜·일부 출고·잔량) / 복제 / 취소 / **삭제**. `고르기`로 여러 건을 한꺼번에 삭제·취소. 지운 주문은 더보기에서 30일 동안 되살릴 수 있습니다.
3. **송장** — CJ·경동·대신별로 아직 안 뽑은 주문이 모여 있습니다. 박스 수·크기(·운임)를 확인하고 `엑셀 받기` 또는 `복사`(기존 엑셀에 붙여넣기). 뽑은 주문은 "송장 뽑음"으로 표시됩니다.
   - 박스는 옛 송장 기록으로 추천합니다. 추천은 참고용이니 확인하세요.
4. **출하서** — 하루 끝에 다 나간 주문은 체크, 일부만 나갔거나 날짜가 다르면 `일부 출고 · 다른 날짜`로 기록하고 `마감하고 하루 파일 받기`. 하루 파일은 엑셀 1개에 출하서·CJ·경동·대신·직납·방문·미출고 탭. 아래 `월 파일 받기`는 `11월.xlsx`처럼 날짜별 출하서 탭 + 거래처별·품목별 합계. 송장 화면 맨 위에는 오늘 출력 수량과 `카톡 보고 복사`, `오늘 뽑은 ○○ 전체 받기`가 있습니다. 나간 것은 출고완료, 나머지는 대기로 남아 다음 날로 넘어갑니다. 지난 출하서는 아래 목록에서 다시 받을 수 있습니다.
5. **생산 화면** — 앱 주소 끝에 `?view=line` 을 붙이면 생산용 화면(폰). 오늘·다음 출고와 아직 만들 양을 보고, 주문마다 `준비완료`·`송장부착`(직납은 `출고준비`)을 누릅니다. 받는분 전화·주소는 안 보이고 주문 수정은 안 됩니다. 더보기에서 사무실 암호와 생산 암호를 따로 정하세요.
6. **더보기** — 거래처 주소록, 옛 엑셀 가져오기(CJ·경동·대신 파일), 접속 암호.

## 엑셀 양식
사무실에서 쓰던 양식 그대로입니다 (열 순서·머리줄 동일).
- CJ: `건별출력` 14열 · 경동: `발송자료` 26열 · 대신: 날짜 탭 + 발화주별 표 · 출하서: `yyyy/mm/dd-출고현황`

## 자세한 구조·배포
`HANDOFF.md`(작업 인수인계), `DEPLOY.md`(처음 한 번 설정), `CHANGELOG.md`(자동 기록).
