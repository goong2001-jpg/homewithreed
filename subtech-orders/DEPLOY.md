# 주문앱 자동 배포 설정 (처음 한 번, PC 권장 · 약 10분)

재고앱 때 만든 로그인 열쇠(`CLASPRC_JSON`)를 그대로 씁니다. **새로 넣을 값은 2개**뿐입니다.
설정 전에는 배포 작업이 "설정 없음"으로 건너뛰기만 하므로 아무 영향이 없습니다.

## 1. 새 Apps Script 프로젝트 만들기
1. 재고 스프레드시트 **주인 구글 계정**으로 https://script.google.com 접속 → **새 프로젝트**
2. 왼쪽 위 이름을 `써브텍 주문앱`으로 바꾸기 (재고앱 프로젝트와 **다른** 프로젝트여야 합니다)
3. 왼쪽 **⚙️ 프로젝트 설정** → **스크립트 ID** 복사

## 2. GitHub에 스크립트 ID 넣기
GitHub 저장소 → **Settings → Secrets and variables → Actions → New repository secret**

| Name (정확히 이대로) | Secret |
|---|---|
| `ORDERS_SCRIPT_ID` | 1-3의 스크립트 ID |

## 3. 코드 올리기 (첫 실행)
Claude에게 **"Secrets 넣었어"** 라고 말하면 Claude가 이 브랜치에 푸시해서 배포 작업을 실행시킵니다.
- (GitHub Actions의 Run workflow 버튼은 기본 브랜치에 있는 워크플로에만 나타나서, 이 브랜치에서는 안 보입니다)
- 초록 체크가 뜨면 Apps Script 프로젝트에 코드가 올라간 것입니다. 아직 웹앱 주소는 없고 "배포 ID 없음, 코드만 올림" 안내가 뜹니다.

## 4. 웹앱으로 배포 (주소 만들기 — 이때 한 번만 "새 배포")
1. Apps Script 편집기 새로고침 → 오른쪽 위 **배포 > 새 배포**
2. 유형 **웹 앱** · 실행 계정 **나** · 액세스 권한 **모든 사용자** → **배포**
3. **액세스 승인** → 계정 선택 → (고급 > 이동) → **허용** (스프레드시트 접근 권한)
4. 나온 **웹 앱 URL**이 주문앱 주소입니다. 폰 홈 화면·PC 즐겨찾기에 추가하세요.
5. 같은 창의 **배포 ID**(`AKfycb…`) 복사

## 5. GitHub에 배포 ID 넣기
| Name | Secret |
|---|---|
| `ORDERS_DEPLOYMENT_ID` | 4-5의 배포 ID (웹앱 주소 전체를 넣어도 됩니다) |

넣은 뒤 Claude에게 **"배포 ID 넣었어"** 라고 하면 한 번 더 푸시해서 자동 배포가 되는지 확인합니다.
이후에는 코드가 올라올 때마다 **같은 주소**로 자동 배포됩니다. "새 배포"는 다시 누르지 마세요(주소가 바뀝니다).

## 6. 처음 열었을 때
1. 앱을 열면 스프레드시트에 `주문`, `주문_거래처`, `주문_송장기록`, `주문_설정` 탭이 자동으로 생깁니다. (재고 탭은 건드리지 않습니다)
2. **더보기 > 옛 엑셀 가져오기**에서 CJ·경동·대신 엑셀 파일을 고르면 주소록과 박스 추천용 기록이 들어옵니다. (PC에서 하세요)
3. 주소가 밖으로 새면 받는분 전화·주소가 보입니다. **더보기 > 접속 암호**를 권합니다.

## 꼭 알아둘 점
- 코드는 GitHub에서만 고칩니다. 자동 배포가 Apps Script 프로젝트 파일을 통째로 바꿉니다.
- 열쇠·ID는 채팅이나 코드에 넣지 말고 GitHub Secrets에만 넣으세요.
