# 엄마아빠 은행 (family-bank)

하율·호윤이 어른들께 받은 돈을 **엄마아빠 은행**에 맡기고, 실제 은행처럼 연 이자와 출금 승인을 겪어 보는 가족은행 PWA입니다.
진짜 돈은 엄마아빠가 보관하고, 앱은 통장 역할만 합니다.

## 1단계 (지금)

* **입출금통장**: 아이마다 하나. 지폐 버튼으로 맡기기, 누가 줬는지 고르기. 이어서 누르면 한 줄로 합쳐집니다.
* **찾기 신청 → 엄마아빠 승인**: 아이는 신청만 합니다. 엄마아빠가 비밀번호로 승인하면 통장에서 빠지고, 그때 진짜 돈을 건넵니다.
  승인 기다리는 돈까지 합쳐서 잔액을 넘게는 신청할 수 없습니다.
* **연 이자 (기본 연 3.5%, 시중은행 1년 정기예금 수준)**: 하루 끝 잔액 × 연 이자율 ÷ 365 를 한 달 모아 다음 달 1일에 원 단위 버림으로 넣습니다.
  앱을 몇 달 안 열어도 다음에 열 때 밀린 달 이자를 한 달씩 넣습니다. "이번 달 쌓이는 이자"는 소수점까지 보여줍니다.
  2026년 10월 초 시중은행 1년 정기예금이 연 3.4~3.6%입니다(하나 3.60%, 신한 3.50%). 세금 15.4%를 떼면 약 2.96%로 물가(2.9%)와 겨우 비깁니다.
  나중에 "예금만으로는 돈이 크게 늘지 않는다"를 보여주려는 설계입니다.
* **이자 세금 15.4%** (설정에서 켜기): 이자가 들어올 때 세금 줄이 따로 찍힙니다.
* **물가 비교 카드** (설정에서 켜기, 기본 꺼짐): 지금 잔액으로 "1년 뒤 통장 vs 1년 뒤 같은 물건 값"을 비교합니다.
  기본 물가 상승률 2.9% = 2026년 9월 소비자물가 전년동월비 (국가데이터처, 2026-10-02 발표). 설정에서 바꿀 수 있습니다.
* **통장 내역**: 실제 통장처럼 `찾으신 돈 / 맡기신 돈 / 남은 돈`.
* **엄마아빠 모드**: 처음 누르면 비밀번호(숫자 4~8자리)를 정합니다. 10분이 지나거나 화면을 떠나면 저절로 잠깁니다.
  이 모드에서 이자율·세금·물가 카드·아이 이름 설정, 통장 내역 한 줄 지우기, 백업을 합니다.
* **용돈기입장 잔액 옮겨오기**: 같은 기기에서 쓰던 구름이 용돈기입장(`allowance`)의 남은 돈을 지금 고른 아이 통장에 한 줄로 맡깁니다.
  용돈기입장 기록은 건드리지 않습니다.

## 7살이 재밌게 (버전 4)

* **이유 칸**: 맡길 때 "왜 받았어요?", 찾을 때 "왜 찾아요?"를 자유롭게 적습니다. 칩(누가/어디)과 함께 `할머니 · 생일 선물`처럼 내역에 남습니다.
* **동전 소리·떨어지는 동전**: 맡기면 짤랑 소리와 함께 동전이 통장으로 떨어집니다. 소리는 설정에서 끌 수 있습니다.
* **소리로 듣기**: 글을 다 못 읽어도 "하율이 통장에는 75,000원이 있어요. 레고 사려면 …원 더 모아야 해요"를 읽어 줍니다.
* **갖고 싶은 것 모으기**: 이름과 금액을 정하면 저금통 막대가 차오르고, 다 모으면 바로 찾기 신청으로 이어집니다.
  물가 비교 카드를 켜면 "이자로만 모으면 약 N년"도 같이 보여서 예금이 느리다는 걸 체감합니다.
* **이자 받는 날 도장**: 매달 1일 이자가 들어오면, 아이 화면을 처음 열 때 도장과 함께 "+37원" 축하 창이 한 번 뜹니다.

## 다음 단계 (기획)

* 2단계: 적금(만기·중도해지), 대출(잔액 50% 한도, 대출 이자 > 예금 이자, 신용도장)
* 3단계: 공과금 자동이체, 투자상품(안전·아빠 펀드·모험), 예금 vs 투자 비교

## 저장 위치 (중요)

서버가 없습니다. 기록은 **그 기기 브라우저(localStorage)에만** 저장됩니다.
은행 기기는 한 대로 정해서 쓰고, 엄마아빠 설정의 `백업 파일 저장`으로 가끔 백업하세요. 백업 불러오기는 지금 통장을 백업 내용으로 **바꿉니다**.
비밀번호는 아이가 쉽게 못 보게 하는 정도의 잠금입니다(기기에 그대로 저장됨).

## 테스트

```bash
cd family-bank
python3 -m http.server 8139 &
node test/smoke.js     # playwright 필요
```

## 업데이트 (배포할 때 꼭)

`app.js` 의 `APP_VERSION`, `index.html` 의 `?v=`, `sw.js` 의 `CACHE`·`SHELL`, `version.json` 을 **같은 숫자로 같이** 올립니다.
