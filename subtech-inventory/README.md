# 써브텍 재고관리 시스템

휴대폰에서 입고/출고를 빠르게 기록하면 현재고가 자동으로 합산되는 Google 스프레드시트 기반 재고관리 프로그램입니다.

> 🔁 **이어서 작업하거나 인수인계할 때는 [`HANDOFF.md`](HANDOFF.md)부터** — 구조, 규칙, 테스트·배포 방법, 전체 변경 이력(v1~)이 정리돼 있습니다.

- **새 스프레드시트**: [써브텍 재고관리 시스템](https://docs.google.com/spreadsheets/d/1ZsMIBsYPHO5bPx0tuvyx15OPq9ljmZ_vY-1C_jF4LiI/edit)
- **기존 써브텍**(원본, 그대로 보존): 초기 재고를 한 번 가져오는 용도로만 사용

## 핵심 개념

| 기존 방식 | 새 방식 |
|---|---|
| 재고 숫자를 직접 고침 | **입고/출고만 기록 → 현재고 자동 계산** |
| 입수가 다른 박스 때문에 칸을 나눔 | **`박스수 × 박스당 수량`을 줄마다 입력**해 낱개로 자동 환산 |
| 누가 언제 했는지 사라짐 | 모든 거래가 `거래로그`에 담당자와 함께 기록 |

## 시트 구성 (초기 설정 시 자동 생성)

| 탭 | 내용 |
|---|---|
| `품목마스터` | 품명 · 분류 · 기본박스입수 · 안전재고 |
| `거래로그` | 모든 입고/출고/기초재고 기록 (자동 누적) |
| `현재고` | 거래로그를 자동 합산한 실시간 재고 (수식) |
| `위치` | 보관 위치 목록 (A동1층 · A동2층 · A동3층 · B동1층 · B동2층) — 여기에 추가하면 앱 위치 선택지에 바로 반영 |
| `설정` | 담당자 목록 |

> 기존 `수량`/`수량2`는 **1층 / 2층 재고**로 가져옵니다. 새 시스템에는 `수량2` 같은 칸이 없고, 같은 품목이 위치별로 따로 집계됩니다.

## 메뉴 (📦 재고관리)

| 메뉴 | 동작 |
|---|---|
| ① 초기 설정 (탭/구조 생성) | 탭·헤더·위치·담당자 생성. **재고는 건드리지 않음** → 몇 번 눌러도 안전 |
| 🧹 전체 재고 0으로 초기화 | 모든 품목·위치 수량을 0으로. 거래로그는 지우지 않고 '조정' 줄을 덧붙임(이력 유지). 품목 목록·메모·BOM·위치도(📌지정)는 유지. 재고앱 🧮총수량 탭 아래 버튼으로도 가능("초기화" 입력) |
| (선택) 기존 써브텍에서 한 번 가져오기 | 기존 써브텍의 재고+업체사양을 1회 가져오기 (안 눌러도 됨) |

> 기존엔 초기 설정이 매번 재고를 다시 불러와 꼬였는데, 이제 **가져오기는 별도 메뉴로 분리**되어 재실행해도 재고가 변하지 않습니다.

## 설치 방법

1. 새 스프레드시트를 연다 → 메뉴 **확장 프로그램 > Apps Script**
2. `Code.gs` 내용을 붙여넣는다. (기본 `Code.gs` 내용은 지우고 교체)
3. 좌측 **＋ > HTML** 으로 `Index` 파일을 만들고 `Index.html` 내용을 붙여넣는다. (이름은 반드시 `Index`)
   - 위치도: **＋ > 스크립트** 로 `Location`(→ `Location.gs`), **＋ > HTML** 로 `Location`(→ `Location.html`)을 만들고 각각 붙여넣는다.
4. 저장 후 스프레드시트로 돌아가 새로고침 → 상단에 **📦 재고관리** 메뉴가 생긴다.
5. **📦 재고관리 > ① 초기 설정 / 기존 재고 가져오기** 실행
   - 권한 승인 1회 필요 (기존 써브텍을 읽기 위함)
   - 완료되면 품목과 현재 재고가 채워진다.
6. Apps Script 화면에서 **배포 > 새 배포 > 유형: 웹 앱**
   - 실행: **나**, 액세스: **모든 사용자**
   - 생성된 **웹 앱 URL**을 휴대폰에서 열고 **홈 화면에 추가** → 앱처럼 사용

## 사용법 (휴대폰)

1. **입출고** 탭에서 품명 검색 → 품목 선택
2. **＋입고 / －출고** 선택
3. 박스 구성 입력 (`90 × 100`, `1 × 90` 처럼 입수가 다르면 줄 추가) → 합계 자동
4. 보관 위치 · 담당자 선택 → **저장**
5. **현재고** 탭에서 분류별 재고와 안전재고 미달 품목 확인

## 안전재고 알림

`품목마스터`의 `안전재고` 열에 숫자를 넣으면, 현재고가 그 아래로 떨어질 때 현재고 화면에서 빨간색으로 표시됩니다.

## 주요 기능

- **입출고**: 품명 검색 → +입고/−출고 → `박스수 × 박스당수량`(입수 혼합 시 줄 추가) → 위치·담당자 선택 → 저장
  - **현재고 → 결과 미리보기**: `현재 3,960 → 입고 후 4,050` 실시간 표시 (출고 시 재고 부족 경고)
  - **최근 입출고 이력**: 선택 품목의 입고/출고/날짜/담당자 기록을 바로 확인
  - **품명/분류 수정**: `✏️ 품명/분류 수정`으로 이름 변경 (거래로그까지 자동 반영)
- **현재고**: 분류 필터 + **수량순/이름순 정렬**, **분류별 색상 구분**, 수량 강조, 위치별 집계, 안전재고 경고.
  품목을 누르면 **바로 입출고 화면으로 연결**됩니다.
- **새 품목 추가 / 삭제**: 품명·분류·박스입수·안전재고 등록, 중복/오입력 정리.
- **메모(업체 사양)**: 업체별 **명판·상호스티커·날짜스티커·전용케이스·프로그램 O/X**, 프로그램명, 비고와
  **상호스티커 사진·명판 사진·추가 사진**을 기록하고 검색. 카드의 `수정`으로 사진을 개별 삭제/교체할 수 있습니다.
  사진은 Drive 폴더(`써브텍 재고 - 메모 이미지`)에 저장됩니다.

## 입출고 화면

- **입고 / 출고 / 조정 / 이동** 4가지 모드
  - 조정(실사): 선택한 위치의 **실제 수량을 입력**하면 차액만 자동 기록 → 전체 재고를 바로 수정
  - 이동: **보내는 위치 → 받는 위치**와 수량만 입력하면 한 번에 위치 이동 (사진 첨부 가능)
- **품명/분류/박스입수/안전재고**를 `✏️ 수정`에서 앱으로 바로 수정
- **위치별 현재고**를 칩으로 표시 (A동1층 990 · A동2층 100)
- **박스수 표기**: `기본박스입수`가 입력된 품목은 `≈ 130박스 +50` 처럼 표시
- **최근 입출고 이력**: 박스수까지 표시하고, 각 줄의 **취소**로 거래를 되돌릴 수 있음(재고 원복 — v34부터 줄을 지우지 않고 **반대 줄(메모 `취소: …`)을 덧붙임**, 이동은 두 줄을 한 번에)
- **적재 위치 사진**: 입고/출고/조정 시 **어디에 뒀는지 사진 첨부**(위치별 **최대 5장**) → 이력과 `📍 최근 적재 사진`에 표시되어 물건 위치를 바로 확인 (사진은 Drive에 저장, `거래로그`의 `사진` 열에 콤마로 여러 개 저장)

## 조립 가능 수량 (BOM)

앱의 **🧩 조립** 탭에서 `＋ 새 조립 레시피`로 **완제품과 필요 부품을 직접 등록/수정/삭제**할 수 있습니다.
(시트의 `BOM` 탭에 직접 적어도 됩니다.) 완제품 1개당 필요한 부품을 한 줄씩 적습니다.

| 완제품품명 | 완제품분류 | 부품품명 | 부품분류 | 소요수량 |
|---|---|---|---|---|
| STT1.3 | 완포 | STT1.3 | 기판 | 1 |
| STT1.3 | 완포 | STT1.3 | 케이스 | 1 |
| STT1.3 | 완포 | 1난방 파워코드 | 파워코드 | 1 |

→ 앱의 **🧩 조립** 탭에서 부품 재고로 **몇 개를 만들 수 있는지**와 **병목 부품**(부족한 부품)을 자동 계산합니다.

**▶ 조립 실행**: 카드의 `▶ 조립 실행`으로 수량을 입력하면 **BOM대로 부품이 자동 차감(조립출)되고 완제품이 자동 입고(조립입)** 됩니다. 부품이 부족하면 부족 목록을 알려주고 실행되지 않습니다.

## 전체 이력

현재고 화면의 **`🕒 이력`** 버튼 → 모든 품목의 최근 입출고 60건을 날짜별로 확인(누가 뭘 했는지 감사용). 각 행에서 `취소`로 거래를 되돌릴 수 있습니다.

## 월별 입출고 리포트

- 앱: **현재고 화면의 `📅 월별` 버튼** → 월별 입고/출고/순증감
- 시트: **`월별리포트` 탭**이 거래로그를 자동 집계(연/월/구분/합계)

## 메모(업체 사양) 자동 이관

초기 설정 시, 기존 써브텍의 **업체 사양표**(명판/상호스티커/날짜스티커/전용케이스/프로그램)를 메모 탭으로 가져옵니다.
사진칸은 **상호스티커·명판·날짜스티커·추가** 4종입니다. (메모가 비어있을 때만 가져오므로, 테스트 메모가 있으면 메모 탭을 비우고 다시 초기 설정하세요.)

## 업체 사양 페이지 → 메모 탭 반영 (`SpecMemos.gs`, 권장)

claude.ai의 "써브텍 업체 사양 조회" 페이지(사람이 정리한 266개 업체)를 메모 탭에 넣습니다. **아래 SeedMemos(카톡 자동추출 375건)의 최신·정리본**이라 이것만 쓰면 됩니다.

**가장 쉬운 방법**: 스프레드시트 메뉴 **📦 재고관리 > 📝 업체사양 메모 가져오기** → 몇 곳 추가/건너뛸지 확인창 → `예`. 되돌리기는 같은 메뉴의 **↩ 메모 탭 최근 백업으로 되돌리기**.

또는 Apps Script 편집기 위쪽 함수 목록에서 고르고 ▶ 실행 → 아래 **실행 로그** 확인:
1. `specMemos_1_미리보기` — 저장 없이 몇 건 추가/고침/건너뛸지
2. `specMemos_2_샘플5건` — 5건만 반영해서 앱 메모 탭에서 확인
3. `specMemos_3_전체반영` — 나머지 전부
- 되돌리기: `specMemos_9_백업으로되돌리기` (실행 전 자동으로 만든 `메모_백업_날짜` 탭으로 복원)

- 메모 탭에 같은 업체가 **없으면 추가**, 예전 **자동등록 행만 있으면 O/X·비고를 최신으로 고침**(사진·프로그램명 유지), **손으로 쓴 메모가 있으면 건드리지 않음**
- X = 아직 확인 안 됨(사양 페이지와 같은 뜻), 확인필요 업체는 비고 앞에 `[확인필요] `, 비고 끝에 `(업체사양 2026-10-27)`
- 여러 번 실행해도 같은 내용은 다시 쓰지 않음. 편집기에서 스크립트 주인만 실행 가능

## 업체 사양 메모 초기 데이터 일괄 등록 (`SeedMemos.gs`)

카톡 대화에서 추출한 375개 업체 사양을 메모 탭에 한 번에 넣는 **별도 스크립트 파일**입니다. `Code.gs`와 `Index.html`은 건드리지 않으므로 **웹앱을 새로 배포할 필요가 없습니다.** (앱은 메모 탭을 실시간으로 읽음)

Apps Script 편집기 상단 함수 목록에서 골라 **[실행]**, 결과는 아래 **[실행 로그]** 에서 확인합니다.

| 함수 | 동작 |
|---|---|
| `seedMemos_1_미리보기` | 저장 없이 추가/건너뛰기 건수만 확인 (dryRun) |
| `seedMemos_2_샘플5건` | 주문 많은 순 앞 5건만 등록 (백업 탭 자동 생성) |
| `seedMemos_3_전체등록` | 나머지 전부 등록 (이미 들어간 업체는 건너뜀, 여러 번 눌러도 안전) |
| `seedMemos_8_삭제미리보기` | 되돌리기 대상 건수만 확인 |
| `seedMemos_9_되돌리기` | 이 파일로 넣은 메모만 삭제 (백업 탭 자동 생성) |

- 이미 메모가 있는 업체(띄어쓰기·대소문자 무시)는 **덮어쓰지 않고 건너뜀**, 목록은 로그에 표시
- 넣은 메모는 작성자 `카톡자동추출`, 비고 끝에 `(카톡자동추출 2026-09-28)` — 되돌리기는 이 꼬리표가 있는 행만 지움
- `확인필요`로 표시된 업체는 비고 앞에 `[확인필요] `가 붙음 → 앱 메모 검색창에 `확인필요` 입력하면 모아볼 수 있음
- 실행 전 `메모` 탭을 `메모_백업_YYYYMMDD` 탭으로 자동 복사
- **편집기에서 스크립트 주인이 실행할 때만** 동작 (웹앱 링크로 외부에서 호출해도 차단)

## 자재 위치도 📍 (`Location.gs` + `Location.html`)

**v15부터 한 화면**: 앱을 열면 **위치도가 첫 화면**이고, 아래 메뉴 `📍위치도 · ➕입출고 · 📊현재고 · 🧩조립 · 📝메모`로 바로 오갑니다.
(Index.html 안에 Location.html 을 끼워 넣음 — `doGet`이 템플릿으로 `<?!= locInclude() ?>`)

- **빠르게**: 앱을 열 때 서버를 **한 번만** 부릅니다(`appBoot` = 품목·재고·위치 + 위치도). 이후 탭 전환은 서버를 다시 부르지 않고,
  입출고·이동 결과는 두 화면이 서로 바로 반영합니다. 다른 앱에 2분 넘게 있다가 돌아오면 위치도·현재고·검색 화면일 때 조용히 최신으로 새로고침.
- **자재별 위치·총수량**: 위치도 검색창에 품명 → `SV7 · 총 9,668개` 아래로 위치별 수량(많은 순, 📌지정 칸 포함). 줄을 누르면 그 칸으로 이동.
  칸 안 재고 목록에서 품명을 눌러도 같은 정보가 나오고 `재고앱에서 입출고`로 바로 이동.

### 입출고 연동 (v13)

위치도의 **칸이 곧 보관 위치**입니다.

- **위치 이름 규칙**: `시트이름 칸코드` (예: `A동1층 B1`), 칸을 층으로 나눴으면 2층부터 `A동1층 B1 2층`.
  칸 이름(선반1 등)은 화면 표시용이라 **바꿔도 재고가 끊기지 않습니다.**
- **칸에 실제 재고가 자동 표시**됩니다 (굵은 숫자 = 거래로그 합계). 손으로 적은 내용은 "메모"로 그대로 함께 보입니다.
- 칸을 누르면 **현재 재고** 목록 → `출고` / `이동` 버튼, 그리고 **`＋ 이 칸에 입고`** → 재고앱 입출고 화면이 그 칸으로 맞춰져 열립니다.
- 입출고 화면의 **보관 위치 선택지**가 위치도 시트별로 묶여 나옵니다: `시트이름 (칸 미지정)` + 이름(또는 메모)이 있는 칸.
  위치도에 없는 `위치` 탭 이름은 `기타 위치`로 아래에 남습니다. 기본 선택은 예전처럼 `위치` 탭 첫 줄입니다.
- 입출고 화면 **`📍 위치도에서 보기`** → 위치도가 그 품목 검색 상태로 열립니다.
- **기존 재고(`A동1층` 등)는 그대로**입니다. 위치도 시트 이름을 `A동1층`으로 맞추면 그 재고가 그 시트의 **📦 칸 미지정 재고**로 보이고, `이동`으로 칸에 배정하면 됩니다.
  어느 시트와도 맞지 않는 위치(옛 이름 `1층` 등)는 **시트에 연결 안 된 재고**에 모입니다.
- **위치도 안에서 이동** (재고앱으로 안 넘어감):
  - 품목 옆 **`이동`** → 그 품목만 / **`⇄ 1층(2층·칸) 전체 이동`** → 그 층의 모든 품목 / **`⇄ 칸째로 이동`** → 층이 나뉜 칸 전체 (1층→1층, 2층→2층)
  - 노란 줄무늬가 뜨면 **받을 칸을 누르기** (다른 시트 탭으로 가서 골라도 됨). 받을 칸이 층으로 나뉘어 있으면 몇 층인지 고름
  - 확인 화면에서 품목별 수량(기본 = 전부)·담당자 확인 → **`⇄ 이동 저장`**. 거래로그에 앱 이동과 같은 `이동` 2줄로 남고(비고 끝 `(위치도)`), 재고앱 이력에서 `취소`도 됨
  - 층·칸 전체 이동은 **직접 적은 메모도 같이 옮기기**(기본 체크) 가능
  - 칸 미지정 재고·연결 안 된 재고도 같은 방법으로 칸에 배정
  - 그 사이 다른 사람이 출고해서 수량이 모자라면 아무것도 기록하지 않고 알려줌
- **줄·칸 옮기기** (도구 버튼): 줄(A·B·C…) 또는 칸(1·2·3…)을 통째로 다른 자리로. 칸 이름·메모·층·📌지정 제품·재고가 같이 가고,
  받는 자리에 내용이 있으면 **서로 자리를 바꿉니다**. 재고는 `이동`으로 기록(비고 `B줄↔C줄 (위치도)`).
  여러 줄·칸에 걸친 합친 칸이 있으면 먼저 풀어야 합니다.
- **📌 제품 지정**: 칸(층)을 누르고 `＋ 제품 지정` → 품목 검색해서 고르기. 재고가 0이어도 칸에 `📌품명 0`으로 보이고 검색에도 걸립니다.
  재고앱에서 그 품목을 고르면 **입고 위치가 지정 칸으로 자동 선택**되고, 위치별 현재고에 `📌 … (지정)`으로 표시됩니다. `✕`로 해제.
  층·칸 전체 이동, 칸 합치기, 층 없애기 때 지정도 같이 옮겨집니다. `위치목록` 탭에는 `[제품] 품명`으로 나옵니다.
- 위치도 변경과 재고 이동은 **한 번에 저장**(locApply) — 그 사이 다른 사람이 위치도를 고쳤거나 재고가 모자라면 아무것도 바뀌지 않습니다.
- **시트 이름 바꾸기·삭제**: 시트 설정에서 `이름 바꾸기` 버튼 → 칸 재고도 새 이름으로 같이 이동(이력 `이동`).
  시트 삭제 시 칸 재고는 `시트이름`(칸 미지정)으로 옮긴 뒤 삭제. 시트 이름으로 기록된 칸 미지정 재고는 그대로 남음(같은 이름 시트가 없으면 "연결 안 된 재고").
- **크기 정리**: 시트 설정 `✂ 남는 빈 줄·칸 한 번에 지우기` (내용 있는 마지막 줄·칸까지 자동으로 줄임).
  가운데 빈 줄·칸은 `줄·칸 옮기기 → 🗑 지우기` (✓ 표시 = 바로 지울 수 있음, 뒤쪽이 한 칸씩 당겨지고 재고는 바뀐 칸 이름으로 `이동`).
- **보기 크기**: 도구 오른쪽 `가−` / `가＋` 로 칸·글자 크기 4단계 (이 기기에 기억). 칸 안 품목은 한 줄에 하나, 📌지정 제품은 노란 막대.
- **재고 보호**: 재고가 있는 칸은 종류 변경·다른 칸에 합치기·층 없애기·줄/칸 줄이기가 막히고, 같은 이름의 시트는 만들 수 없습니다.

### 칸별 수량 입력 · 총수량 탭 (v24)
- 위치도 **✏️ 수량 입력**을 켜고 칸을 누르면 📌지정 제품(과 그 칸에 재고가 있는 품목)마다 입력칸이 바로 열립니다. **박스 수 × 박스당 수량** 줄(＋ 박스 줄로 여러 개) + **낱개**의 합계가 그 칸의 수량이 됩니다. 박스당 수량은 품목의 기본값이 미리 들어가요. 아무것도 안 적은 품목은 그대로. **저장 → 다음 칸** (v25)

- 위치도 맨 앞 **🚫 재고X** 버튼(표시한 개수 배지) → 발주 목록: 품목·분류·현재 총수량·📌칸·표시한 날/사람, **해제**, **📋 발주 목록 복사**(카톡에 붙여넣기), 품목 찾아 표시.

### 검색 (v30) — 위치도·입출고·총수량 공통

- 결과 위 **분류 칩**(전체·기판 2·완포 4…)으로 좁히기, 고른 칩은 폰에 기억 (그 검색에 없으면 자동으로 전체).

### 위치도에서 바로 출고 (v29)
- 칸 창의 재고 줄 **출고** → 위치도 안에서 출고 창이 열립니다 (재고앱 탭으로 안 넘어감). 박스 줄(박스 수 × 박스당 수량) + 낱개, '이 칸 전부', 메모(출고처), 담당자. 칸 수량보다 많으면 확인을 한 번 더 묻습니다. 저장(`locQuickOut`) 뒤 칸 창으로 돌아와요. 거래로그 메모: `위치도에서 출고 · 메모`.

### 지금 보는 시트 표시 (v26)
- 시트마다 색이 정해져 있어(시트 순서대로) 탭 윗줄, 선택된 탭, 지도 위 **📍 시트이름 · 시트 n/N** 표시줄과 지도 배경이 그 색으로 바뀝니다. 표시줄의 ◀ ▶로 시트를 넘기고, 화면을 내려도 표시줄은 위에 붙어 있어요. 칸 패널 제목에도 시트 이름이 색 배지로 붙습니다.

### `위치` 탭 (보관 위치 선택지)

| 열 | 헤더 | 의미 |
|---|---|---|
| A | `위치` | **거래로그에 기록되는 이름(조인 키).** 필수 — 입출고 화면의 위치 선택지 |
