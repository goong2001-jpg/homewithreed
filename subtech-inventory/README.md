# 써브텍 재고관리 시스템

휴대폰에서 입고/출고를 빠르게 기록하면 현재고가 자동으로 합산되는 Google 스프레드시트 기반 재고관리 프로그램입니다.

- **새 스프레드시트**: [써브텍 재고관리 시스템](https://docs.google.com/spreadsheets/d/1ZsMIBsYPHO5bPx0tuvyx15OPq9ljmZ_vY-1C_jF4LiI/edit)
- **기존 써브텍**(원본, 그대로 보존): 초기 재고를 한 번 가져오는 용도로만 사용

## 핵심 개념

| 기존 방식 | 새 방식 |
|---|---|
| 재고 숫자를 직접 고침 | **입고/출고만 기록 → 현재고 자동 계산** |
| 입수가 다른 박스 때문에 칸을 나눔 | **`박스수 × 박스당 수량`을 줄마다 입력**해 낱개로 자동 환산 |
| 누가 언제 했는지 사라짐 | 모든 거래가 `거래로그`에 담당자와 함께 기록 |

## 시트 구성 (초기 설정 시 자동 생성)

| 탭 | 내용 |
|---|---|
| `품목마스터` | 품명 · 분류 · 기본박스입수 · 안전재고 |
| `거래로그` | 모든 입고/출고/기초재고 기록 (자동 누적) |
| `현재고` | 거래로그를 자동 합산한 실시간 재고 (수식) |
| `위치` | 보관 위치 목록 (1층 · 2층 · A동 · B동 · 창고) — 여기에 추가하면 앱 위치 선택지에 바로 반영 |
| `설정` | 담당자 목록 |

> 기존 `수량`/`수량2`는 **1층 / 2층 재고**로 가져옵니다. 새 시스템에는 `수량2` 같은 칸이 없고, 같은 품목이 위치별로 따로 집계됩니다.

## 메뉴 (📦 재고관리)

| 메뉴 | 동작 |
|---|---|
| ① 초기 설정 (탭/구조 생성) | 탭·헤더·위치·담당자 생성. **재고는 건드리지 않음** → 몇 번 눌러도 안전 |
| 🧹 전체 재고 0으로 초기화 | 거래로그를 비워 모든 재고를 0으로. 품목 목록·메모·BOM·위치는 유지 |
| (선택) 기존 써브텍에서 한 번 가져오기 | 기존 써브텍의 재고+업체사양을 1회 가져오기 (안 눌러도 됨) |

> 기존엔 초기 설정이 매번 재고를 다시 불러와 꼬였는데, 이제 **가져오기는 별도 메뉴로 분리**되어 재실행해도 재고가 변하지 않습니다.

## 설치 방법

1. 새 스프레드시트를 연다 → 메뉴 **확장 프로그램 > Apps Script**
2. `Code.gs` 내용을 붙여넣는다. (기본 `Code.gs` 내용은 지우고 교체)
3. 좌측 **＋ > HTML** 으로 `Index` 파일을 만들고 `Index.html` 내용을 붙여넣는다. (이름은 반드시 `Index`)
4. 저장 후 스프레드시트로 돌아가 새로고침 → 상단에 **📦 재고관리** 메뉴가 생긴다.
5. **📦 재고관리 > ① 초기 설정 / 기존 재고 가져오기** 실행
   - 권한 승인 1회 필요 (기존 써브텍을 읽기 위함)
   - 완료되면 품목과 현재 재고가 채워진다.
6. Apps Script 화면에서 **배포 > 새 배포 > 유형: 웹 앱**
   - 실행: **나**, 액세스: **모든 사용자**
   - 생성된 **웹 앱 URL**을 휴대폰에서 열고 **홈 화면에 추가** → 앱처럼 사용

## 사용법 (휴대폰)

1. **입출고** 탭에서 품명 검색 → 품목 선택
2. **＋입고 / －출고** 선택
3. 박스 구성 입력 (`90 × 100`, `1 × 90` 처럼 입수가 다르면 줄 추가) → 합계 자동
4. 보관 위치 · 담당자 선택 → **저장**
5. **현재고** 탭에서 분류별 재고와 안전재고 미달 품목 확인

## 안전재고 알림

`품목마스터`의 `안전재고` 열에 숫자를 넣으면, 현재고가 그 아래로 떨어질 때 현재고 화면에서 빨간색으로 표시됩니다.

## 주요 기능

- **입출고**: 품명 검색 → +입고/−출고 → `박스수 × 박스당수량`(입수 혼합 시 줄 추가) → 위치·담당자 선택 → 저장
  - **현재고 → 결과 미리보기**: `현재 3,960 → 입고 후 4,050` 실시간 표시 (출고 시 재고 부족 경고)
  - **최근 입출고 이력**: 선택 품목의 입고/출고/날짜/담당자 기록을 바로 확인
  - **품명/분류 수정**: `✏️ 품명/분류 수정`으로 이름 변경 (거래로그까지 자동 반영)
- **현재고**: 분류 필터 + **수량순/이름순 정렬**, **분류별 색상 구분**, 수량 강조, 위치별 집계, 안전재고 경고.
  품목을 누르면 **바로 입출고 화면으로 연결**됩니다.
- **새 품목 추가 / 삭제**: 품명·분류·박스입수·안전재고 등록, 중복/오입력 정리.
- **메모(업체 사양)**: 업체별 **명판·상호스티커·날짜스티커·전용케이스·프로그램 O/X**, 프로그램명, 비고와
  **상호스티커 사진·명판 사진·추가 사진**을 기록하고 검색. 카드의 `수정`으로 사진을 개별 삭제/교체할 수 있습니다.
  사진은 Drive 폴더(`써브텍 재고 - 메모 이미지`)에 저장됩니다.

## 입출고 화면

- **입고 / 출고 / 조정** 3가지 모드
  - 조정(실사): 선택한 위치의 **실제 수량을 입력**하면 차액만 자동 기록 → 전체 재고를 바로 수정
- **위치별 현재고**를 칩으로 표시 (A동1층 990 · A동2층 100)
- **박스수 표기**: `기본박스입수`가 입력된 품목은 `≈ 130박스 +50` 처럼 표시
- **최근 입출고 이력**: 박스수까지 표시하고, 각 줄의 **취소**로 거래를 되돌릴 수 있음(재고 원복)
- **적재 위치 사진**: 입고/출고/조정 시 **어디에 뒀는지 사진 첨부** 가능 → 이력과 `📍 최근 적재 사진`에 표시되어 물건 위치를 바로 확인 (사진은 Drive에 저장, `거래로그`의 `사진` 열)

## 조립 가능 수량 (BOM)

앱의 **🧩 조립** 탭에서 `＋ 새 조립 레시피`로 **완제품과 필요 부품을 직접 등록/수정/삭제**할 수 있습니다.
(시트의 `BOM` 탭에 직접 적어도 됩니다.) 완제품 1개당 필요한 부품을 한 줄씩 적습니다.

| 완제품품명 | 완제품분류 | 부품품명 | 부품분류 | 소요수량 |
|---|---|---|---|---|
| STT1.3 | 완포 | STT1.3 | 기판 | 1 |
| STT1.3 | 완포 | STT1.3 | 케이스 | 1 |
| STT1.3 | 완포 | 1난방 파워코드 | 파워코드 | 1 |

→ 앱의 **🧩 조립** 탭에서 부품 재고로 **몇 개를 만들 수 있는지**와 **병목 부품**(부족한 부품)을 자동 계산합니다.

## 월별 입출고 리포트

- 앱: **현재고 화면의 `📅 월별` 버튼** → 월별 입고/출고/순증감
- 시트: **`월별리포트` 탭**이 거래로그를 자동 집계(연/월/구분/합계)

## 메모(업체 사양) 자동 이관

초기 설정 시, 기존 써브텍의 **업체 사양표**(명판/상호스티커/날짜스티커/전용케이스/프로그램)를 메모 탭으로 가져옵니다.
사진칸은 **상호스티커·명판·날짜스티커·추가** 4종입니다. (메모가 비어있을 때만 가져오므로, 테스트 메모가 있으면 메모 탭을 비우고 다시 초기 설정하세요.)

## 보관 위치

기본값: `A동1층 · A동2층 · A동3층 · B동1층 · 창고`. `위치` 탭에서 추가/수정하면 앱에 바로 반영됩니다.
초기 가져온 재고는 `수량 → A동1층`, `수량2 → A동2층`로 적재됩니다.

## ⚠️ 코드를 새로 붙여넣은 경우 (업데이트 시) 꼭 하세요

메모의 사진 첨부 때문에 **Drive 권한**이 새로 필요합니다.

1. Apps Script에서 `Code.gs` / `Index.html`을 최신 내용으로 교체 후 저장
2. 스프레드시트 새로고침 → **📦 재고관리 > ① 초기 설정** 다시 실행
   → 이때 **Drive 접근 권한 승인**이 한 번 더 뜹니다. 허용하세요. (기존 데이터는 보존됩니다)
3. Apps Script → **배포 > 배포 관리 > (연필)수정 > 버전: 새 버전 > 배포**
   → 이렇게 하면 **URL은 그대로 유지**되면서 최신 코드로 갱신됩니다.
