- **v34부터는 자동 기록**: `claude/spreadsheet-accessibility-opmsi3`(또는 `main`)에 푸시 → 자동 배포가 **성공하면** GitHub Actions가 그 커밋 메시지로 아래에 한 항목씩 추가합니다 (`dev/changelog.js`, 봇 커밋 `[skip ci] 변경 이력 자동 기록`).

- 시간은 한국 시간(KST). 최신이 위.
