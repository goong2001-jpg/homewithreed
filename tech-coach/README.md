# 기술 설명 8주 (tech-coach)

FDS 경력자가 8주 동안 웹 서비스 구조(화면-서버-DB-외부 AI API)와 AI 용어를 이해하고,
심사위원·면접관 질문에 **2문장으로 정확히** 답하는 연습을 하는 앱입니다.
Claude 코칭 세션(`CLAUDE.md`)과 같이 쓰고, 휴대폰에서 혼자 복습할 때 엽니다.

빌드 없는 정적 앱이라 폴더 그대로 GitHub Pages 에 올라갑니다.
배포 주소: `https://goong2001-jpg.github.io/homewithreed/tech-coach/`

- `data.js` — 진단·커리큘럼·질문·용어 콘텐츠. 모범 답의 "N건, N초, N원"은 실습에서 잰 숫자로 바꾼다.
- `app.js` — 화면과 동작
- `test/smoke.js` — `python3 -m http.server 8151 &` 후 `node test/smoke.js`
- `CLAUDE.md`, `LEARNING_LOG.md`, `GLOSSARY.md` — Claude 코칭 세션용 (배포에서는 빠짐)
